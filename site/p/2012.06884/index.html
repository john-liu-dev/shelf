AIR-FI: Generating Covert Wi-Fi Signals from Air-Gapped Computers

恶意软件借内存总线发射 Wi-Fi 信号，从物理隔离电脑窃取数据

论文表明攻击者可以通过 Wi-Fi 信号从物理隔离（air-gapped）计算机中窃取数据：被攻陷的隔离机器上的恶意软件能利用内存总线在 Wi-Fi 频段产生信号，不需要特殊硬件，并把敏感数据调制到信号上。附近具备 Wi-Fi 能力的设备（手机、笔记本、IoT 设备）可截获并解码，再通过互联网发给攻击者。作者实现了发射端和接收端，评估了带宽与距离，并给出一组防御措施，结果显示数据可传到几米之外的 Wi-Fi 接收器。

HN 为什么提它

HN 评论者把它当作「物理隔离电脑也能通过 Wi-Fi 信号泄露数据」的例子引用，认为这个结果已经足够有意思，不需要夸大。

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径沿着 Mordechai Guri 团队的物理隔离计算机隐蔽信道系列，从热、声、光到电力线，逐步建立不同信道的威胁模型，再读 Wi-Fi 信号外泄。

  1. 1
    BitWhisper
    BitWhisper: Covert Signaling Channel between Air-Gapped Computers using Thermal ManipulationsBitWhisper：利用热量变化在物理隔离的计算机间建立隐蔽信道 · 2015

    该系列早期工作，首次定义气隙计算机间的隐蔽信道威胁模型。

    读气隙隔离的威胁模型、发送端与接收端的设定，以及热信道的带宽与限制。

  2. 2
    Fansmitter
    Fansmitter: Acoustic Data Exfiltration from (Speakerless) Air-Gapped ComputersFansmitter：从（无扬声器的）物理隔离计算机中声学窃取数据 · 2016

    展示无扬声器的情况下仍可借风扇噪声外泄，说明如何绕过常见防护。

    读利用风扇转速调制的编码方式、接收端距离与速率。

  3. 3
    LED-it-GO
    LED-it-GO: Leaking (a lot of) Data from Air-Gapped Computers via the (small) Hard Drive LED2017

    用硬盘指示灯做光学隐蔽信道，说明如何在不同物理载体上调制数据。

    读调制与编码方式，以及传输速率、距离的评估。

  4. 4
    MOSQUITO
    MOSQUITO: Covert Ultrasonic Transmissions between Two Air-Gapped Computers using Speaker-to-Speaker Communication2018

    利用扬声器到扬声器的超声通信，在已有声学信道思路上进一步扩展。

    读扬声器反向当作麦克风的机制，以及两台隔离计算机之间的通信流程。

  5. 5
    PowerHammer
    PowerHammer: Exfiltrating Data from Air-Gapped Computers through Power LinesPowerHammer：通过电力线从物理隔离计算机中窃取数据 · 2018

    通过电力线外泄数据，是与本文同一作者的另一个无需专用硬件的发射方式。

    读靠调控 CPU 负载在电力线上形成信号的机制，以及外泄速率和检测方法。

  6. 6
    AIR-FI
    AIR-FI: Generating Covert Wi-Fi Signals from Air-Gapped ComputersAIR-FI：从物理隔离计算机生成隐蔽 Wi-Fi 信号 · 2020 · 就是这篇

    目标论文：借内存总线在 Wi-Fi 频段产生信号并外泄数据。

    读内存总线产生信号的原理、利用物理层信息接收的做法，以及防御对策。
