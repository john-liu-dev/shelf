报告讨论一种新技术，即在设备端分析明文数据、命中目标内容时向执法部门报告的客户端扫描（CSS），支持者称它既保留端到端加密又能侦查严重犯罪。作者论证 CSS 既不能保证有效预防犯罪，也无法阻止监控，效果反而相反：它本质上会给整个社会带来严重的安全与隐私风险，对执法的帮助至多也是有问题的，并且有多种失效、被规避和被滥用的方式。

HN 为什么提它

评论者在 CSS 与加密后门的争论中引用这份由顶级安全专家撰写的报告，说明客户端扫描无法在技术上变得可信，危害不亚于加密后门。

学习路径

读这篇之前，按顺序读书架上的 4 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

候选里与客户端扫描直接相关的是深度网络的对抗样本与后门，它们说明了机器学习检测器可以被规避或被利用，这是该报告论证风险的技术背景。

  1. 1
    Intriguing properties of neural networks
    Intriguing properties of neural networks神经网络的有趣性质 · 2013

    对抗样本概念的起点，说明基于神经网络的内容匹配可以被微小扰动欺骗。

    读微小扰动致误分类的现象。

  2. 2
    Explaining and Harnessing Adversarial Examples
    Explaining and Harnessing Adversarial Examples解释并利用对抗样本 · 2014

    给出快速生成对抗样本的方法，说明规避扫描成本很低。

    读快速梯度符号法的核心思路。

  3. 3
    Universal adversarial perturbations
    Universal adversarial perturbations通用对抗扰动 · 2016

    一个通用扰动即可让分类器大面积出错，提示扫描器很难靠单一模型可靠判断。

    读通用扰动的构造与跨图像的有效性。

  4. 4
    BadNets
    BadNets: Identifying Vulnerabilities in the Machine Learning Model Supply ChainBadNets：识别机器学习模型供应链中的漏洞 · 2017

    展示模型供应链中可被植入后门，说明被扫描的模型本身也可能被利用。

    读后门触发器的设置，以及外包训练带来的风险。
