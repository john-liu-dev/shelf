高能物理（HEP）研究需要大量计算与存储，通常用 Python 做高层接口、C++ 做计算密集部分。论文探讨用同时具备高层编程与高性能的 Julia 语言做 HEP 研究的可行性，覆盖运行时性能、大型项目管理、与遗留代码的接口、分布式计算、培训和编程易用性等方面。结论是 HEP 社区将从大规模采用 Julia 中受益，并指出了需要整合巩固的 HEP 专用基础库。
