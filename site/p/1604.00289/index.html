文章回顾认知科学的进展，指出基于端到端深度神经网络的系统虽在物体识别、电子游戏和棋类上达到甚至超过人类，但与人类智能在关键方面不同。作者主张类人机器应：构建支持解释与理解的世界因果模型；以直觉物理和直觉心理学为学习的基础；利用组合性和学会学习（learning-to-learn）快速习得并泛化知识，并提出结合神经网络与结构化认知模型的具体挑战和路线。

HN 为什么提它

HN 上的人把它当作「当前 AI 方法为什么不足、类人学习应该怎样」的易读综述来推荐，多用于支持因果模型与类人推理的论点。

观点难度 3 / 5约 90 分钟经得起时间
读之前最好知道
1深度学习基础
2认知科学中的直觉物理与心理学
3因果模型（causal model）与贝叶斯推断
4组合性与迁移学习（learning-to-learn）

学习路径

读这篇之前，按顺序读书架上的 7 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先看深度学习的整体进展，再看这篇文章用来对照的几类系统：图像描述、带注意力的生成、结构化生成模型、外部记忆和分层 / 内在动机 RL，最后读认知科学视角的批评。

  1. 1
    Deep Learning in Neural Networks
    Deep Learning in Neural Networks: An Overview神经网络中的深度学习：综述 · 2014

    给出深度学习的整体背景，便于理解目标论文所说的端到端网络成就。

    读略读历史脉络与主要成果。

  2. 2
    Show and Tell
    Show and Tell: A Neural Image Caption GeneratorShow and Tell：神经图像描述生成器 · 2014

    目标论文用图像描述系统说明网络能产出流畅句子却缺乏真正理解。

    读CNN 编码加 LSTM 解码的结构；留意它的失败案例。

  3. 3
    Show, Attend and Tell
    Show, Attend and Tell: Neural Image Caption Generation with Visual Attention展示、注意与讲述：带视觉注意力的神经图像描述生成 · 2015

    带视觉注意力的描述模型，是文中讨论的一个代表。

    读软 / 硬注意力的做法和可视化。

  4. 4
    DRAW
    DRAW: A Recurrent Neural Network For Image GenerationDRAW：用于图像生成的循环神经网络 · 2015

    DRAW 是逐步生成图像的神经模型，文中拿来和人类的概念生成作对比。

    读注意力窗口加循环生成的框架；不必推导变分下界。

  5. 5
    Attend, Infer, Repeat
    Attend, Infer, Repeat: Fast Scene Understanding with Generative Models2016

    Attend, Infer, Repeat 把场景理解做成结构化生成模型，靠近目标论文主张的组合性与因果模型。

    读逐步推断场景中物体个数与属性的框架。

  6. 6
    Learning to Transduce with Unbounded Memory
    Learning to Transduce with Unbounded Memory学习使用无界记忆进行序列转换 · 2015

    为循环网络引入栈、队列等可微记忆，对应文中关于网络需要更强记忆与算法结构的讨论。

    读可微栈 / 队列的接口思想。

  7. 7
    Hierarchical Deep Reinforcement Learning
    Hierarchical Deep Reinforcement Learning: Integrating Temporal Abstraction and Intrinsic Motivation2016

    分层强化学习结合内在动机，对应文中关于目标、分层与规划的讨论。

    读元控制器与子目标控制器的分层结构。

  8. 8
    Building Machines That Learn and Think Like People
    Building Machines That Learn and Think Like People构建像人一样学习和思考的机器 · 2016 · 就是这篇

    目标论文：从认知科学角度提出类人 AI 需要的核心要素。

    读因果模型、直觉物理与直觉心理、组合性与学会学习几个核心主张，再看对深度网络现状的评论。
