JShelter: Give Me My Browser Back

JShelter：把浏览器还给我
Libor Polčák, Marek Saloň, Giorgio Maone, Radek Hranický, Michael McMahon · 2022

介绍防指纹追踪、限制危险 Web API 的浏览器扩展 JShelter

这是一篇立场论文，介绍浏览器扩展 JShelter 及一个帮助开发 webextension 的库，目标是防止浏览器指纹识别、限制功能丰富的 Web API、防范与计时相关的攻击以及设备信息泄露。作者还发现 Chromium 系浏览器在启用传感器 API 时，传感器时间戳会让任意页面观察到设备的开机时间。JShelter 可输出指纹报告，供后续安全研究和数据保护机构使用。

评论者在讨论 JShelter 这个扩展时，把这篇论文当作解释其设计思路的学术出处。
