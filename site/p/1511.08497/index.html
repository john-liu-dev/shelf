SWIM 根据“generate md5 hash code”这类自然语言查询建议代码片段：先用 Bing 点击数据把查询映射到相关 API，再基于开源代码中学到的用法模式合成惯用代码，并提出带 if 分支和 while 循环的“结构化调用序列”来表示 API 用法。在 30 个 C# 查询上，70% 的首个结果相关，所有查询的前 10 个结果中都有相关方案，平均每个片段 1.5 秒。
