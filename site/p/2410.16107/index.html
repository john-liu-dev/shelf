作者用 Llama 3 的多个变体和 GPT-4o，基于相同提示构造人类与 LLM 的平行语料，并用 Douglas Biber 的词汇、语法和修辞特征集进行比较。结果发现人类与 LLM、以及不同 LLM 之间存在系统性的风格差异，这些差异不因模型变大而消失，且指令微调模型的差异比基座模型更大。

HN 为什么提它

评论者用它解释 LLM 文本为什么有可辨认的“AI 腔”：差异不只在用词，还在语法和修辞，且指令微调模型比基座模型更明显；作者本人也在评论中现身。
