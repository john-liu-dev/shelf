光学（optics）是对子字段访问、容器遍历等数据变换模式的双向访问器，profunctor 表示支持模块化组合。论文指出此前研究只限于非丰富、非混合的设定，而函数式语言更适合用丰富范畴描述，并发现文献中的一些结构其实是访问方向落在不同范畴里的混合光学。作者推广了 Pastro 与 Street 关于 Tambara 理论的经典结果，用它描述混合的 V-丰富 profunctor 光学并赋予 V-范畴结构，给出一些原创的光学族和推导（包括遍历的初等推导），最后讨论了 Haskell 实现。

HN 为什么提它

HN 上的人把它当作把 Haskell 常用的 lens 模式形式化到范畴论里的出处，也有人引它的表格查阅较冷门的 optics，并用范畴论视角推广到其他容器。

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

    Physics, Topology, Logic and Computation
    Physics, Topology, Logic and Computation: A Rosetta Stone物理、拓扑、逻辑与计算：罗塞塔石碑 · 2009

    读对称幺半范畴的基本概念与例子，不必深入物理部分。

  2. 2
    Compositional game theory
    Compositional game theory组合博弈论 · 2016

    读开放博弈如何用双向结构组合。
