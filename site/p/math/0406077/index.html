这是对 Rissanen 最小描述长度（MDL）原理的教程性介绍：第一章从概念上非技术地讲解，第二章把这些想法在数学上精确化。内容是《Advances in Minimum Description Length》一书前两章的扩展版。

HN 为什么提它

评论者在 ML 阅读清单（出自 Sutskever 的清单）里提到它，并用它说明 MDL 的思想：最好的模型是总描述最短的模型。
