XNOR-Net: ImageNet Classification Using Binary Convolutional Neural Networks

XNOR-Net：用二值卷积神经网络做 ImageNet 分类
Mohammad Rastegari, Vicente Ordonez, Joseph Redmon, Ali Farhadi · 2016

把卷积网络权重甚至输入二值化，省内存且可在 CPU 实时运行

论文提出对标准卷积神经网络的两种高效近似：Binary-Weight-Networks 把滤波器近似为二值，节省 32 倍内存；XNOR-Networks 则让滤波器和卷积层输入都是二值，主要用二值运算近似卷积，卷积运算快 58 倍、内存节省 32 倍，使 CPU 上实时运行先进网络成为可能。在 ImageNet 上，Binary-Weight 版 AlexNet 的 top-1 准确率仅比全精度低 2.9%，并比 BinaryConnect 和 BinaryNets 高出超过 16%。

HN 为什么提它

HN 上的人把它当作 1 比特量化网络的早期代表，在讨论低精度推理、硬件加速器和后来的二值网络工作时反复引用，用来说明极低精度是可行的。

学习路径

读这篇之前，按顺序读书架上的 7 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径先看为什么要压缩网络（浅网络、剪枝、小模型），再看二值权重的前作 BinaryConnect，最后读 XNOR-Net 如何把输入也二值化。

    Do Deep Nets Really Need to be Deep?
    Do Deep Nets Really Need to be Deep?深度网络真的需要很深吗？ · 2013

    读浅层网络模仿深层网络的做法和结论；实验细节可略读。

  2. 2
    Learning both Weights and Connections for Efficient Neural Networks
    Learning both Weights and Connections for Efficient Neural Networks2015

    剪枝是与二值化并列的压缩路线，可用来比较省内存的方法。

    读按权重大小剪枝再重训练的流程；了解即可。

  3. 3
    SqueezeNet
    SqueezeNet: AlexNet-level accuracy with 50x fewer parameters and <0.5MB model sizeSqueezeNet：参数少 50 倍、模型小于 0.5MB 的 AlexNet 级精度 · 2016

    同样追求小模型，是 XNOR-Net 论文里比较压缩效果的对象。

    读Fire 模块的设计与参数量与精度的关系。

  4. 4
    Deep Learning with Limited Numerical Precision
    Deep Learning with Limited Numerical Precision有限数值精度下的深度学习 · 2015

    展示低精度数值训练网络的可行性，是二值化想法的铺垫。

    读随机舍入下低位宽训练为何能保持精度。

    BinaryConnect

    XNOR-Net 的 Binary-Weight-Network 直接建立在它的二值权重训练之上。

    读前向用二值权重、反向用实数权重更新的训练方法。

  6. 6
    Batch Normalization
    Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift批归一化：通过减少内部协变量偏移加速深度网络训练 · 2015

    XNOR-Net 在二值卷积前做批归一化，需要理解其作用。

    读批归一化的计算方式与作用，对照 XNOR-Net 里的层顺序。

  7. 7
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    XNOR-Net 在 ResNet 等网络上做二值化实验。

    读残差块结构，便于读懂二值化实验里的网络配置。

  8. 8
    XNOR-Net

    目标论文：Binary-Weight-Networks 与 XNOR-Networks。

    读二值权重的缩放因子最优解的推导，以及用 XNOR 加位计数近似卷积；再看 ImageNet 实验。
