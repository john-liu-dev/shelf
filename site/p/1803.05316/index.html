这是一本通过具体的现实例子介绍高等范畴论主题的书，全书分为七篇素描，每篇把一个应用场景（如数据库、电路、动力系统）与一种范畴结构（如伴随函子、enriched category、topos）配对。它不要求读者事先学过范畴论，定位是一次温和而快速的导览。

HN 为什么提它

HN 上的人把它当作对非数学家也友好的范畴论入门，强调每章起步都很容易，并常拿它和更传统的范畴论教材比较、作为课程教材推荐。

教程难度 3 / 5约 1200 分钟经得起时间
读之前最好知道
1基本的集合与函数概念
2偏序（partial order）与基础抽象代数
3一定的数学阅读习惯与耐心
4对数据库或电路等应用背景的初步了解

学习路径

读这篇之前，按顺序读书架上的 2 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这本教材用数据库和动力系统作例子，这条路径先看两篇用范畴论做具体建模的论文，对应书中数据库与拓扑斯相关的几个素描。

  1. 1
    Functorial Data Migration
    Functorial Data Migration2010

    用函子描述数据库间的数据迁移，对应书中把数据库当作范畴、模式映射当作函子的那部分。

    读抓「模式是范畴、实例是函子」的基本想法和伴随函子给出的迁移；技术细节可略。

  2. 2
    Temporal Type Theory
    Temporal Type Theory: A topos-theoretic approach to systems and behavior时态类型论：一种面向系统与行为的拓扑斯理论方法 · 2017

    用拓扑斯语义描述系统与行为，是书中动力系统、拓扑斯等主题的进一步应用。

    读只读引言，理解如何用层与拓扑斯描述随时间变化的系统；不必追证明。

  3. 3
    Seven Sketches in Compositionality
    Seven Sketches in Compositionality: An Invitation to Applied Category Theory组合性七篇素描：应用范畴论邀请 · 2018 · 就是这篇

    借具体应用入门应用范畴论。

    读按七个素描顺序读，每个素描先看应用例子再看对应的范畴结构。
