提出 ReAct：让 LLM 交替生成推理轨迹和任务相关的行动，推理帮助模型制定、跟踪和更新行动计划并处理异常，行动则让它借助知识库或环境获取额外信息。在 HotpotQA 和 Fever 上，ReAct 通过调用简单的 Wikipedia API，缓解了思维链中常见的幻觉和误差传播；在 ALFWorld 和 WebShop 上，仅用一两个上下文示例，成功率分别比模仿学习和强化学习方法高 34% 和 10%（绝对值）。

HN 为什么提它

评论者把它当作 LLM agent 的基础范式：模型先说明意图再调用工具，被 LangChain 等框架采用，并作为构建自主 agent 和调试 agent 行为时的原始出处。
