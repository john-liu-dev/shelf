为了同时获得灵活性与可处理性，作者受非平衡统计物理启发：通过迭代的前向扩散过程系统而缓慢地破坏数据分布中的结构，然后学习一个恢复结构的反向扩散过程，得到灵活且可处理的数据生成模型。这使得在有数千层或时间步的深度生成模型中也能快速学习、采样和评估概率，并可计算学到模型下的条件概率和后验概率；论文同时发布了开源参考实现。

HN 为什么提它

HN 上的人把它当作扩散模型的源头来引用，称它在 2015 年就提出了生成式扩散模型，并把它当作学习扩散模型文献的起点（但数学较重）。

奠基之作难度 5 / 5约 90 分钟经得起时间
读之前最好知道
1概率分布与变分下界（variational lower bound）
2马尔可夫链（Markov chain）
3生成模型基础（如 VAE、GAN）
4统计物理中的扩散过程

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先理解变分自编码器和可逆流模型这两类生成模型，以及评估生成模型的难点，再读扩散模型的最初形式。

  1. 1
    Auto-Encoding Variational Bayes
    Auto-Encoding Variational Bayes自编码变分贝叶斯 · 2013

    VAE 的变分下界与目标论文训练反向过程时用的下界思想相通。

    读变分下界（ELBO）的含义与重参数化。

  2. 2
    NICE
    NICE: Non-linear Independent Components Estimation2014

    NICE 是同期另一种精确似然的生成模型，可与扩散模型的可计算性目标对照。

    读可逆变换与精确对数似然。

  3. 3
    A note on the evaluation of generative models
    A note on the evaluation of generative models2015

    讨论生成模型的评估方式，帮助理解目标论文为什么强调对数似然与可计算性。

    读对数似然与样本质量不总是一致的结论。

  4. 4
    Deep Unsupervised Learning using Nonequilibrium Thermodynamics
    Deep Unsupervised Learning using Nonequilibrium Thermodynamics利用非平衡热力学的深度无监督学习 · 2015 · 就是这篇

    目标论文：用逐步加噪的前向扩散与学到的反向去噪过程构造灵活且可处理的生成模型。

    读前向扩散核、反向过程的参数化、训练目标（对数似然下界），以及去噪与图像修复应用。
