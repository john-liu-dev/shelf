大语言模型通常在语言空间中通过思维链（CoT）推理，但语言空间未必最适合推理：多数词 token 只维持文本连贯，并非推理所必需。作者提出 Coconut（连续思维链）：把模型最后的隐藏状态作为推理状态，称为「连续思维」，不解码成词，而是直接作为下一步的输入嵌入回馈给模型。这种潜空间推理能编码多个备选的下一步，使模型能做类似广度优先搜索的推理，而不是像 CoT 那样过早确定单一路径；在需要大量搜索规划的逻辑推理任务上，Coconut 优于 CoT，并在准确率与效率之间取得更好的权衡。

每当有人谈到让模型在潜空间里推理而不是用英文 token 思考（neuralese）时，评论者就拿 Coconut 作为 Meta 的代表性研究来引用。
