指出机器学习学术中的四种趋势：(i) 不区分解释与猜测；(ii) 不去识别经验提升的来源，例如收益其实来自超参数调优却强调不必要的结构改动；(iii) mathiness，即用数学来迷惑或装点而非阐明；(iv) 滥用语言，如选用带日常含义的术语或重载已有术语。作者推测原因包括社区快速扩张、审稿人池变薄、学术激励与短期指标错位，并给出一些尝试性的改进建议。

HN 为什么提它

评论者引用它批评 ML 论文质量，并用来说明 CS 研究和其他领域一样不可靠，以及 mathiness（第 3.3 节）这一问题只增不减。

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径用几个具体的例子（批归一化、可解释性、强化学习评测、解释权）为目标论文的批评提供背景，再读它的总结。

  1. 1
    Batch Normalization
    Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift批归一化：通过减少内部协变量偏移加速深度网络训练 · 2015

    目标论文把「内部协变量偏移」作为猜测被当作解释的典型例子。

    读原文中对 internal covariate shift 的解释方式；读目标论文时对照「猜测未经验证」的批评。

  2. 2
    How Does Batch Normalization Help Optimization?
    How Does Batch Normalization Help Optimization?Batch Normalization 如何帮助优化？ · 2018

    它用实验表明批归一化有效的原因并不是原先所说的那样，是上一篇的后续检验。

    读主要实验：BN 并没有减少内部协变量偏移，而是平滑了优化地形。

  3. 3
    The Mythos of Model Interpretability
    The Mythos of Model Interpretability模型可解释性的迷思 · 2016

    目标论文批评术语滥用，「可解释性」是其中重点例子。

    读作者对可解释性不同含义的分类；对应目标论文关于术语含糊的论述。

  4. 4
    European Union regulations on algorithmic decision-making and a "right to explanation"
    European Union regulations on algorithmic decision-making and a "right to explanation"欧盟算法决策法规与“解释权” · 2016

    目标论文引用它说明「解释权」等术语在政策讨论中的含糊使用。

    读文中对 GDPR 与算法决策的讨论，思考与目标论文批评的关联。

  5. 5
    Deep Reinforcement Learning that Matters
    Deep Reinforcement Learning that Matters真正重要的深度强化学习 · 2017

    它是关于评测严谨性与可复现性的实证研究，与目标论文关心的经验严谨性同方向。

    读不同实现与超参数对深度 RL 结果的影响，以及作者的报告建议。

    Troubling Trends in Machine Learning Scholarship
