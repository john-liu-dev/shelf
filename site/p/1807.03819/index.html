Transformer 这类前馈序列模型在复制字符串、当长度超出训练范围时做简单逻辑推理等任务上泛化失败，而循环模型却能轻松处理。论文提出通用 Transformer（UT）：一种在时间上并行的自注意力循环序列模型，可视为 Transformer 的推广，结合了 Transformer 的并行性与全局感受野和 RNN 的循环归纳偏置，并加入逐位置的动态停机机制。在一定假设下 UT 可被证明图灵完备，在多种算法与语言理解任务上优于标准 Transformer，在 LAMBADA 上达到新的最好结果，在 WMT14 英德翻译上比 Transformer 高 0.9 BLEU。

HN 为什么提它

评论者把它作为早期的循环式 Transformer（跨深度共享权重）引用，常在讨论递归或循环式小模型、说明这类想法早已有之时提到。

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径帮我建立 Universal Transformer 的前置知识：seq2seq 与 Transformer 的基础、算法任务与记忆网络，再看它如何把循环归纳偏置加到 Transformer 上。

  1. 1
    Sequence to Sequence Learning with Neural Networks
    Sequence to Sequence Learning with Neural Networks用神经网络进行序列到序列学习 · 2014

    循环 seq2seq 是 Universal Transformer 所对照的基本范式，理解它才看得出循环归纳偏置的位置。

    读抓编码器-解码器与逐步循环状态的做法。

  2. 2
    Attention Is All You Need
    Attention Is All You Need注意力就是你所需要的一切 · 2017

    Universal Transformer 直接建立在 Transformer 之上，只是把层间的参数改为共享并加循环。

    读抓多头自注意力、位置编码和编码器-解码器的整体结构。

  3. 3
    Learning to Execute
    Learning to Execute学习执行 · 2014

    Learning to Execute 的任务是目标论文评测算法能力的任务来源之一。

    读抓该任务的设置（程序执行、加法），便于看懂实验。

  4. 4
    Towards AI-Complete Question Answering
    Towards AI-Complete Question Answering: A Set of Prerequisite Toy Tasks迈向 AI 完备的问答：一组前置玩具任务 · 2015

    bAbI 是目标论文用来评测推理能力的基准。

    读抓任务的类型划分与评测方式，了解每个任务考察的推理能力。

  5. 5
    End-To-End Memory Networks
    End-To-End Memory Networks端到端记忆网络 · 2015

    端记忆网络是 bAbI 上的代表性方法，可作为目标论文的对比。

    读抓多跳注意力读取记忆的机制，类比 UT 的多步循环。

  6. 6
    Universal Transformers
    Universal Transformers通用 Transformer · 2018 · 就是这篇

    目标论文：以逐位置的循环加动态停止机制结合 Transformer 并行性与 RNN 的归纳偏置。

    读抓层间参数共享的循环、ACT 动态停止（每个位置自适应的步数），以及算法任务和 bAbI 上的结果。
