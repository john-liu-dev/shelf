论文在表达力强的 Web 模型中，对 OAuth 2.0 标准做了首个全面的形式化分析，为授权、认证和会话完整性给出形式定义，覆盖全部四种授权类型，并考虑恶意的依赖方、身份提供方和浏览器。证明过程中作者发现四个可在实践中利用的攻击，对 OpenID Connect 同样有效；论文提出修复方案，并首次在表达力强的 Web 模型中证明修复后的 OAuth（遵循安全建议和最佳实践）具有所指定的授权、认证和会话完整性性质。
