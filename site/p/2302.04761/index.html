提出 Toolformer：一个以自监督方式训练、学会决定调用哪些 API、何时调用、传什么参数，以及如何把返回结果用于后续 token 预测的模型，每个 API 只需少量示范。集成的工具包括计算器、问答系统、两种搜索引擎、翻译系统和日历。Toolformer 在多种下游任务上零样本表现大幅提升，往往可与大得多的模型竞争，且不牺牲核心语言建模能力。

HN 为什么提它

评论者围绕它讨论小模型也能把人的意图转成工具调用，并欣赏它在训练中试调 API、比较下一词概率来生成微调数据的做法；多出现在 ChatGPT 类产品讨论里。

方法难度 3 / 5约 45 分钟有时效性
