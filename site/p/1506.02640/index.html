论文提出 YOLO：不同于以往把分类器改用于检测的做法，而是把目标检测看成对空间上分开的边界框及相应类别概率的回归问题，由单个神经网络对整幅图像一次评估就直接预测。整个检测流程是一个网络，可以直接针对检测性能端到端优化。基础 YOLO 模型以每秒 45 帧实时处理图像，小型版本 Fast YOLO 达到每秒 155 帧，mAP 仍是其他实时检测器的两倍。相比最先进系统它定位错误更多，但在背景上误报更少，并且在从自然图像泛化到艺术作品时大幅优于 DPM 和 R-CNN。

HN 为什么提它

HN 上的人把它当作实时目标检测的原版论文，称赞其设计的简洁，常与 R-CNN、SSD 等检测方案相提并论。

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

建立卷积主干网络和两阶段检测器的背景，才能看懂 YOLO 把检测改成单次回归究竟改变了什么。

  1. 1
    Very Deep Convolutional Networks for Large-Scale Image Recognition
    Very Deep Convolutional Networks for Large-Scale Image Recognition面向大规模图像识别的极深卷积网络 · 2014

    YOLO 的对比实验用到 VGG-16 作为主干，也是当时标准的深层卷积网络设计。

    读3x3 卷积堆叠的设计思路与分类网络结构，理解特征提取主干长什么样。

  2. 2
    Going Deeper with Convolutions
    Going Deeper with Convolutions用卷积走得更深 · 2014

    YOLO 的网络结构直接受 GoogLeNet 启发，用 1x1 卷积降维再接 3x3 卷积。

    读Inception 模块与 1x1 降维卷积的作用；不必细看训练技巧。

  3. 3
    Faster R-CNN
    Faster R-CNN: Towards Real-Time Object Detection with Region Proposal NetworksFaster R-CNN：用区域建议网络实现实时目标检测 · 2015

    它是 YOLO 要对比和超越的两阶段检测范式：先出候选框再分类。

    读区域建议网络与 anchor 的概念，以及整条检测流水线分几步，便于对照 YOLO 的统一回归。

  4. 4
    You Only Look Once
    You Only Look Once: Unified, Real-Time Object DetectionYou Only Look Once：统一的实时目标检测 · 2015 · 就是这篇

    有了主干网络和两阶段检测的背景，再看把检测当回归问题的单网络方案。

    读网格划分、每格预测边界框与类别概率、损失函数的设计，以及速度与定位误差的取舍。
