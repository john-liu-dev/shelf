论文提出检索增强生成（RAG）：以预训练的 seq2seq 模型作为参数化记忆，以维基百科的稠密向量索引作为非参数化记忆，并通过预训练的神经检索器访问。作者比较了两种形式，一种在整个生成序列中使用同一批检索段落，另一种每个 token 可用不同段落；在三个开放域问答任务上刷新最好成绩，在语言生成任务上也比纯参数化 seq2seq 基线更具体、多样、符合事实。

HN 为什么提它

评论者把它当作「RAG」这个名称的原始出处来引用，在讨论长上下文的替代方案和生成式搜索时用它说明「检索加生成」的模式。

学习路径

读这篇之前，按顺序读书架上的 7 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先补 Transformer、BERT、T5 这条预训练与序列到序列的主线，再看外部记忆、向量检索索引和 REALM 的检索增强预训练，就能读懂 RAG 把检索器和生成器接在一起的做法。

  1. 1
    Attention Is All You Need
    Attention Is All You Need注意力就是你所需要的一切 · 2017

    RAG 的检索器和生成器都建在 Transformer 之上，先要熟悉这个架构。

    读编码器-解码器结构与多头注意力的概念；跳过机器翻译实验。

  2. 2
    BERT
    BERT: Pre-training of Deep Bidirectional Transformers for Language UnderstandingBERT：用于语言理解的深度双向 Transformer 预训练 · 2018

    RAG 的查询和文档编码器是 BERT 式的双向编码器。

    读预训练加微调的范式，以及 [CLS] 表示怎么用；跳过各任务细节。

  3. 3
    Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer
    Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer探索迁移学习的极限：统一的文本到文本 Transformer · 2019

    RAG 的生成端是文本到文本的序列到序列模型，T5 展示了这种统一形式。

    读文本到文本框架的思路，以及编码器-解码器预训练目标的概念。

  4. 4
    End-To-End Memory Networks
    End-To-End Memory Networks端到端记忆网络 · 2015

    带多跳注意力读取外部记忆，是把外部知识接入神经网络的早期形式。

    读记忆的软注意力读取与多跳机制的概念；理解它与检索式记忆的区别。

  5. 5
    Efficient and robust approximate nearest neighbor search using Hierarchical Navigable Small World graphs
    Efficient and robust approximate nearest neighbor search using Hierarchical Navigable Small World graphs基于分层可导航小世界图的高效、鲁棒近似最近邻搜索 · 2016

    向量检索靠近似最近邻索引，HNSW 是常用的一类图索引。

    读多层邻近图与对数复杂度搜索的基本思路；不必深究建图参数。

  6. 6
    Billion-scale similarity search with GPUs
    Billion-scale similarity search with GPUs基于 GPU 的十亿级相似性搜索 · 2017

    RAG 的文档向量库用 FAISS 做最大内积搜索，这篇是其核心实现依据。

    读乘积量化和 GPU 上 k-选择的概念，弄清为什么能支持亿级文档检索。

  7. 7
    REALM
    REALM: Retrieval-Augmented Language Model Pre-TrainingREALM：检索增强的语言模型预训练 · 2020

    REALM 把可学习的检索器放进语言模型预训练，是 RAG 最直接的同类前作，要对比两者怎么处理检索。

    读检索器与语言模型联合训练的做法，以及检索结果如何作为潜变量被边缘化。

  8. 8
    Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks
    Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks面向知识密集型 NLP 任务的检索增强生成 · 2020 · 就是这篇

    目标论文：把预训练检索器与序列到序列生成器端到端结合，用于知识密集型任务。

    读RAG-Sequence 与 RAG-Token 两种边缘化方式，以及检索器与生成器的联合微调；对照 REALM 看区别。
