论文提出一种简单的文本到图像生成方法：用一个 Transformer 把文本 token 和图像 token 当作单一数据流做自回归建模，而不依赖复杂架构、辅助损失或部件标注、分割掩码等额外信息。在足够的数据和规模下，这种方法以零样本方式评估时可与此前的领域专用模型竞争。

HN 为什么提它

HN 评论者引用它来说明 DALL-E 的训练数据规模约 2.5 亿图文对、使用 BPE dropout 等细节，并概括其要点：可以直接把文本和图像串成一条流喂给 GPT 式模型。

方法难度 3 / 5约 45 分钟有时效性
读之前最好知道
1Transformer 与自回归语言模型
2离散图像 token 化（VQ-VAE 一类）
3BPE 分词
4零样本（zero-shot）评估
