报告发布 DeepSeek-V4 系列预览版，包含 1.6T 参数（49B 激活）的 DeepSeek-V4-Pro 与 284B 参数（13B 激活）的 DeepSeek-V4-Flash 两个 MoE 模型，均支持一百万 token 上下文。主要升级有三点：结合 Compressed Sparse Attention 与 Heavily Compressed Attention 的混合注意力、增强残差连接的 Manifold-Constrained Hyper-Connections（mHC），以及使用 Muon 优化器以加快收敛和提升稳定性；模型在 32T 以上 token 上预训练，并经完整后训练流程。在百万 token 设置下，V4-Pro 的单 token 推理 FLOPs 仅为 DeepSeek-V3.2 的 27%，KV cache 仅为 10%。
