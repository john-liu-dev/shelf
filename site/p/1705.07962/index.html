论文展示可以端到端地训练深度学习模型，从一张图形界面截图直接生成对应的界面代码。在 iOS、Android 和网页三种平台上，生成准确率超过 77%。

HN 为什么提它

评论者把它当作「截图转代码」的早期概念验证，用来说明这类想法已经在网页设计工具里有所应用，并催生了后来的公司。

方法难度 3 / 5约 35 分钟经得起时间

3序列生成与领域特定语言（DSL）

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先掌握序列生成、CNN 特征提取和图像描述生成这几块基础，再看带注意力的图像描述和代码生成前作，最后读 pix2code 如何把截图翻译成界面代码。

  1. 1
    Generating Sequences With Recurrent Neural Networks
    Generating Sequences With Recurrent Neural Networks用循环神经网络生成序列 · 2013

    LSTM 序列生成是 pix2code 解码器生成代码 token 的基础。

    读理解 LSTM 逐个预测下一个符号的做法。

  2. 2
    Very Deep Convolutional Networks for Large-Scale Image Recognition
    Very Deep Convolutional Networks for Large-Scale Image Recognition面向大规模图像识别的极深卷积网络 · 2014

    pix2code 的视觉编码器是 CNN，VGG 是这类深层卷积特征提取的典型设计。

    读理解堆叠小卷积核提取图像特征的结构。

  3. 3
    Show and Tell
    Show and Tell: A Neural Image Caption GeneratorShow and Tell：神经图像描述生成器 · 2014

    CNN 编码图像、LSTM 解码为文字的结构，与 pix2code 从截图生成代码的结构同构。

    读抓住图像编码加语言解码的端到端框架。

  4. 4
    Show, Attend and Tell
    Show, Attend and Tell: Neural Image Caption Generation with Visual Attention展示、注意与讲述：带视觉注意力的神经图像描述生成 · 2015

    给图像到序列的生成加上视觉注意力，是与 pix2code 同类任务的另一种设计。

    读了解软注意力如何在每个输出步聚焦图像区域，对比 pix2code 不用注意力的做法。

  5. 5
    Latent Predictor Networks for Code Generation
    Latent Predictor Networks for Code Generation2016

    神经网络生成程序代码的早期尝试，与 pix2code 目标相近。

    读了解从自然语言描述到代码的生成任务设定，与从截图生成代码对比。

  6. 6
    pix2code
    pix2code: Generating Code from a Graphical User Interface Screenshotpix2code：从图形界面截图生成代码 · 2017 · 就是这篇

    目标论文：用 CNN 加 LSTM 从界面截图端到端生成多平台代码。

    读看 DSL 的设计、视觉与语言两个模型的拼接方式，以及三个平台上的准确率。
