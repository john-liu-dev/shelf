Quiet-STaR: Language Models Can Teach Themselves to Think Before Speaking

Quiet-STaR 是 STaR 的推广：让语言模型在任意文本的每个 token 处生成理由（rationale）来解释后续内容，从而改进预测。为解决生成续写开销大、模型起初不会用内部思考、需预测多个 token 之后等难题，作者提出逐 token 并行采样、用可学习的起止标记表示思考，以及扩展的 teacher forcing。在互联网文本上继续预训练后，零样本 GSM8K 从 5.9% 升至 10.9%，CommonsenseQA 从 36.3% 升至 47.2%，且无需在这些任务上微调。

HN 为什么提它

评论者把它看作比思维链（Chain of Thought）更进一步的方向，也拿它作为「模型先输出一段不外露的思考 token 再回答」这类做法的公开例子。
