A Watermark for Large Language Models

John Kirchenbauer, Jonas Geiping, Yuxin Wen, Jonathan Katz, Ian Miers, Tom Goldstein · 2023

用绿色词表软性偏置采样，给 LLM 文本加水印

提出面向专有语言模型的水印框架：在生成每个词之前随机选出一组绿色 token，采样时软性地提高使用绿色 token 的概率，从而在文本中嵌入人眼不可见、但算法可检测的信号。水印对文本质量影响可忽略，检测无需访问模型 API 或参数，并配有带可解释 p 值的统计检验和信息论分析框架。作者在 OPT 系列的数十亿参数模型上做了测试，并讨论了鲁棒性与安全性。

HN 为什么提它

评论者常把它称为红绿词表方案，是讨论如何识别 AI 生成文本时的标准出处，同时也有人指出这种水印很容易被绕过。
