SPANN 是一个沿用倒排索引思路的内存-磁盘混合 ANNS 系统：把各 posting list 的中心点放在内存，大的 posting list 放在 SSD。建索引时用层次化平衡聚类均衡 posting list 长度，并把聚类闭包内的点补进列表；搜索时用查询感知策略动态裁剪不必要的 posting list。在三个十亿级数据集上，相同内存开销下达到 90% 召回的速度约为 DiskANN 的 2 倍。

HN 为什么提它

评论者把它列为能扩展到超出内存规模的向量索引方案，常与其他向量检索论文放在一起推荐。
