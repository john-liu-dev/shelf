论文给出从图灵机停机问题到 Java 子类型检查的归约，由此得出 Java 的子类型检查不可判定，回答了 Kennedy 和 Pierce 在 2007 年提出的问题。同时说明 Java 的类型检查器可以识别任何递归语言，改进了 Gil 与 Levy 2016 年的结果，并用一个面向流式接口（fluent interface）的解析器生成器来演示这一点。

HN 为什么提它

评论者把它作为“Java 的类型系统本身图灵完备、子类型检查不可判定”的出处引用，常与 Rust、Haskell、Scala、TypeScript 等同样图灵完备的类型系统并列。
