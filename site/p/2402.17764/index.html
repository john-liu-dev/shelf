论文提出 BitNet b1.58，一种 1-bit LLM 变体，其每个参数都是三值 {-1, 0, 1}。作者称在相同模型规模和训练 token 数下，它在困惑度和下游任务上与全精度（FP16 或 BF16）Transformer 相当，同时在延迟、内存、吞吐和能耗上明显更划算。论文还主张这给出了训练高性能且低成本新一代 LLM 的缩放定律与配方，并带来新的计算范式，为专用于 1-bit LLM 的硬件设计打开了空间。

HN 为什么提它

评论者围绕三值权重（-1/0/1）能否用整数加法取代浮点乘加、能否在 FPGA 或专用硬件上跑得更快来讨论，也有人认为“1-bit”命名不准，并怀疑实际可用性不如论文所示。
