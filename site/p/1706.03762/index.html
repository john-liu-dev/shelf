论文提出 Transformer，一种只依赖注意力机制、完全不用循环和卷积的序列转换网络。在 WMT 2014 英德和英法机器翻译任务上，它的质量超过当时的最好结果，并且更易并行、训练成本明显更低；它在英语成分句法分析上也表现良好。

HN 为什么提它

它被反复称为现代大语言模型的奠基论文，HN 上的人把它当作理解 Transformer 架构的原始出处和入门起点，也有人说原文其实并不好读。

奠基之作难度 3 / 5约 50 分钟经得起时间
读之前最好知道
1神经网络基础
2序列到序列模型（seq2seq）与循环神经网络（RNN）
3注意力机制（attention）
4机器翻译与 BLEU 指标

学习路径

读这篇之前，按顺序读书架上的 4 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先理解序列到序列框架和注意力机制如何解决定长向量瓶颈，再了解残差连接和当时的 LSTM 翻译系统，就能看清 Transformer 要取代的是什么。
