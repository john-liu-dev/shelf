论文提出 WikiChat，一个基于英文维基百科、几乎不产生幻觉的少样本 LLM 聊天机器人：先由 LLM 生成回复，仅保留有依据的事实，再与从语料检索的额外信息结合，形成事实准确又有对话感的回答。作者把基于 GPT-4 的 WikiChat 蒸馏到 7B 的 LLaMA 上，损失很小，同时降低延迟、成本和隐私风险。在人类加 LLM 的混合评估中，最佳系统在模拟对话中达到 97.3% 的事实准确率，在近期话题的真人对话中为 97.9%，均显著优于所比较的基线与 GPT-4。

HN 为什么提它

评论者指出其主张针对的是机器人转述维基百科的准确性而非维基百科本身，也把它当作把难任务拆成多个较简单 LLM 调用的例子。

方法难度 3 / 5约 45 分钟有时效性
