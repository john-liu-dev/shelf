论文把幻觉形式化为可计算的 LLM 与可计算的真值函数之间的不一致，并借助学习理论证明：LLM 无法学会所有可计算函数，因此作为通用问题求解器必然会产生幻觉。作者认为形式化世界只是真实世界的一部分，所以真实的 LLM 也不可避免地幻觉，并针对受可证明时间复杂度限制的真实 LLM 描述易幻觉的任务、做了实证验证，还讨论了现有幻觉缓解手段的机制与效果。
