小团队用云平台和开源工具搭建大规模视觉搜索系统

论文展示了借助 Amazon Web Services 等分布式计算平台和开源工具，小型工程团队也能构建、上线并维护低成本的大规模视觉搜索系统，并通过 Pinterest 上全面的线上实验表明，由视觉搜索驱动的内容推荐能提升用户参与度。作者分享了实现细节和从零上线商业视觉搜索引擎的经验，希望视觉搜索能被更广泛地用到商业应用里。

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径先了解图像识别的基准和卷积网络特征，再看如何把现成的 CNN 特征用于检索，最后读 Pinterest 的视觉搜索系统。

  1. 1
    ImageNet Large Scale Visual Recognition Challenge
    ImageNet Large Scale Visual Recognition ChallengeImageNet 大规模视觉识别挑战 · 2014

    视觉搜索使用的深度特征来自在 ImageNet 上训练的网络，需要知道这个基准。

    读任务设置与评测方式；不必细读历年结果。

  2. 2
    Very Deep Convolutional Networks for Large-Scale Image Recognition
    Very Deep Convolutional Networks for Large-Scale Image Recognition面向大规模图像识别的极深卷积网络 · 2014

    系统里使用的是这类深层卷积网络提取的视觉特征。

    读网络结构（3x3 卷积堆叠）与最后全连接层的输出可作为特征。

  3. 3
    CNN Features off-the-shelf
    CNN Features off-the-shelf: an Astounding Baseline for Recognition2014

    说明现成的 CNN 特征不经微调即可用于多种识别与检索任务，是本文用法的依据。

    读用预训练网络的某一层作特征并配合简单分类器或检索的做法与结果。

  4. 4
    Visual Search at Pinterest
    Visual Search at PinterestPinterest 的视觉搜索 · 2015 · 就是这篇

    目标论文：用云平台和开源工具搭建大规模视觉搜索系统，并做线上实验。

    读特征提取与索引服务的系统架构，以及线上实验对用户参与度的影响。
