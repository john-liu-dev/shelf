作者指出当前的强化学习算法在传感器信息被大量遮蔽（部分可观测）时，连简单任务都难以解决；而仅有大容量记忆并不够，关键是以合适的格式存储合适的信息。为此提出 MERLIN（记忆、强化学习与推断网络），由预测建模过程引导记忆的形成，使其能解决部分可观测性严重、需要长时间保持记忆的 3D 虚拟现实任务，并展示一个单一的学习智能体架构即可解决心理学和神经生物学中的经典行为任务，而无需对感官输入维度或经验时长做强简化假设。

    Reinforcement Learning with Unsupervised Auxiliary Tasks
    Reinforcement Learning with Unsupervised Auxiliary Tasks2016

    读读辅助任务（像素控制、奖励预测）如何加速学习，以及它没有显式记忆的局限。

    RL$^2$: Fast Reinforcement Learning via Slow Reinforcement LearningRL²：通过慢速强化学习实现快速强化学习 · 2016

    读读用 RNN 在多个回合里保存信息的做法。

    Learning to reinforcement learn

    读读循环网络如何在任务内适应，对照 MERLIN 用预测来训练记忆。
