这是一本简短的范畴论入门教材，面向数学背景不多的读者（如本科数学前半段）。核心是泛性质（universal property）这一贯穿数学的概念：先用一章引入基本定义，再用三章分别通过伴随函子、可表函子和极限来表达泛性质，最后一章把三者联系起来。每个新概念都配有来自数学不同分支的大量例子，对抽象跨度特别大的地方（如 Yoneda 引理）给出细致而充分的解释。

HN 为什么提它

HN 上的人把它称为读过的最好的范畴论入门，强调它是免费教材、重在建立直觉，并且更好地解释了范畴论为何值得作为一个领域来研究。

学习路径

读这篇之前，按顺序读书架上的 1 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

    Rethinking set theory
    Rethinking set theory重新思考集合论 · 2012

    同一作者用范畴论式的朴素公理重写集合论，可作为范畴论思维方式的预览。

    读抓为什么用映射而非元素关系来刻画集合，这一视角与泛性质一致。

  2. 2
    Basic Category Theory
    Basic Category Theory范畴论基础 · 2016 · 就是这篇

    围绕泛性质的简短范畴论入门。

    读抓基本定义、伴随、可表函子、极限这几条表达泛性质的路径，及它们的统一。
