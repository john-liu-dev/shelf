论文提出 CodeAct：让 LLM 智能体用可执行的 Python 代码作为统一的动作空间，结合解释器，可在多轮交互中根据新观察动态修改或发出新动作。在 API-Bank 和新构建基准上对 17 个 LLM 的分析显示，CodeAct 优于常用替代方案，成功率最高提升 20%。作者还构建了含 7k 条多轮交互的 CodeActInstruct 数据集，并基于 Llama2 与 Mistral 微调出 CodeActAgent。

HN 为什么提它

评论者反复用它来支持「智能体用写代码代替 JSON 调用工具效果更好」这一做法，并在讨论新智能体设计时拿它当先例，也有人强调它在 2024 年就已发表。
