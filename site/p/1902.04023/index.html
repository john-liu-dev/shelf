论文提出计算基于秩的统计量近似值的在线算法，用很小的草图（sketch）就能达到高精度，尤其在分布尾部。其特点是分位数 q 的精度是相对于 max(q, 1-q) 的，而不是像多数方法那样的绝对精度；算法对偏斜分布或有序数据集保持稳健，并且分别计算的摘要可以无损合并。作者提供了 Java 开源实现，另有 Go 和 Python 的独立实现。

HN 为什么提它

评论者用它说明较新的数据结构 t-digest 即使在 99.999% 这样的极端尾部分位数上仍保持很高精度，也有人讨论其评估所用的平均绝对误差。

方法难度 3 / 5约 40 分钟经得起时间
