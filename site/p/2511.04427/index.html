论文用双重差分设计，把采用 Cursor 的 GitHub 项目与匹配的对照项目比较，估计其对开发速度和软件质量的因果效应。结果显示采用 Cursor 会带来统计显著、幅度较大但短暂的项目级开发速度提升，同时静态分析警告和代码复杂度出现大幅且持续的上升；进一步的面板 GMM 估计表明，这两者的增加是长期速度放缓的主要因素。

HN 上的人引用它说明 AI 编程助手的提速效果是短暂的，而静态分析警告和代码复杂度会持续上升。
