BloombergGPT: A Large Language Model for Finance

论文介绍 BloombergGPT，一个在广泛金融数据上训练的 500 亿参数语言模型。作者基于 Bloomberg 的数据来源构建了 3630 亿 token 的数据集，并混入 3450 亿 token 的通用数据集。在标准 LLM 基准、公开金融基准和一套内部基准上验证后，混合数据训练使模型在金融任务上大幅领先现有模型，同时不损失通用基准表现。论文还说明了建模选择、训练过程和评估方法，并在附录 C 发布了训练记录。
