论文先给出对 YOLO 检测方法的一系列改进，得到 YOLOv2：在 PASCAL VOC 2007 上 67 FPS 时达到 76.8 mAP，40 FPS 时达到 78.6 mAP，快于并优于 Faster RCNN 加 ResNet 和 SSD。随后提出检测与分类联合训练的方法，在 COCO 检测数据集和 ImageNet 分类数据集上同时训练，得到 YOLO9000，使没有检测标注的类别也能被检测，可预测 9000 多种类别且仍能实时运行。

HN 为什么提它

HN 上的人在 2017 年前后提到它是 CVPR 2017 荣誉提名的改进版 YOLO，并拿它与 SSD、Faster R-CNN 等检测器比较。

方法难度 3 / 5约 35 分钟有时效性
读之前最好知道
1卷积神经网络（CNN）
2目标检测基础（如 R-CNN、SSD）
3平均精度均值（mAP）
4ImageNet 与 COCO 数据集

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径先建立 CNN 分类骨干和批归一化，再看两阶段检测器 Faster R-CNN，然后读 YOLO v1，最后读 YOLO9000 在其上做的改进。

  1. 1
    Very Deep Convolutional Networks for Large-Scale Image Recognition
    Very Deep Convolutional Networks for Large-Scale Image Recognition面向大规模图像识别的极深卷积网络 · 2014

    YOLO9000 的 Darknet-19 骨干借鉴了 VGG 的 3x3 小卷积堆叠思路，并以它作对比。

    读全部使用 3x3 卷积的设计原则和网络配置；训练细节可略读。

  2. 2
    Batch Normalization
    Batch Normalization: Accelerating Deep Network Training by Reducing Internal Covariate Shift批归一化：通过减少内部协变量偏移加速深度网络训练 · 2015

    YOLO9000 的改进之一是在所有卷积层加批归一化，收益显著。

    读批归一化的计算方式，以及它如何加速训练、起到正则作用。

  3. 3
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    YOLO9000 与 ResNet 版的 Faster R-CNN 做速度和精度对比。

    读残差连接的基本思想和 ResNet 的分类骨干；了解它作为检测对比基线的角色即可。

  4. 4
    Faster R-CNN
    Faster R-CNN: Towards Real-Time Object Detection with Region Proposal NetworksFaster R-CNN：用区域建议网络实现实时目标检测 · 2015

    YOLO9000 的 anchor box、与两阶段方法的比较都以它为参照。

    读区域建议网络（RPN）和 anchor box 的概念；理解两阶段检测为何较慢。

  5. 5
    You Only Look Once
    You Only Look Once: Unified, Real-Time Object DetectionYou Only Look Once：统一的实时目标检测 · 2015

    YOLO9000 是 YOLO v1 的升级版，必须先懂其统一回归式检测。

    读把图像划分网格、每格预测边框和类别的方法，以及 v1 的主要缺陷（定位误差、召回率低）。

  6. 6
    YOLO9000
    YOLO9000: Better, Faster, StrongerYOLO9000：更好、更快、更强 · 2016 · 就是这篇

    目标论文：YOLOv2 的改进集合与 9000 类联合训练。

    读先看 Better 部分的各项改进（批归一化、anchor 聚类、高分辨率等），再看 Stronger 部分的 WordTree 联合训练。
