论文主张：硬件（更大的 GPU 内存、更快的互连与 IO、成本下降）和软件（可组合数据系统、成熟库）的进步已移除 GPU 数据分析普及的主要障碍。作者展示了开源的 GPU 原生 SQL 引擎原型 Sirius，它以 GPU 为主引擎、利用 libcudf，并通过 Substrait 为现有数据库提供即插即用加速。与单机 DuckDB 集成时，Sirius 在 TPC-H 和 ClickBench 上的成本效率分别提高 8.3 倍和 7.4 倍，与 Apache Doris 集成时最多加速 12.5 倍。

HN 为什么提它

评论者关注 Sirius 这类基于 CUDA 的引擎能否在 ZLUDA、SCALE、HIP 等 CUDA 转换层上运行。
