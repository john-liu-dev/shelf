DBOS: A Proposal for a Data-Centric Operating System

DBOS：以数据为中心的操作系统方案
Michael Cafarella, David DeWitt, Vijay Gadepally, Jeremy Kepner, Christos Kozyrakis, Tim Kraska, Michael Stonebraker, Matei Zaharia · 2020

提议把操作系统状态全存为数据库表，任务通过查询来操作

提出基于数据中心架构的全新操作系统设计：全部 OS 状态统一表示为数据库表，并通过无状态任务发出的查询来操作。作者认为这样便于不重构整个系统就扩展和演进 OS、检查和调试系统状态、不停机升级组件、用机器学习做决策，并实现复杂的安全功能；文中还给出了开发 DBOS 概念验证的计划。

评论者把它当作像操作 SQL 数据库一样与操作系统或云交互这一愿景的出处，并有人追问它后来是否演变成了工作流服务。
