论文提出 modular implicits，一种受 Scala implicits 和模块化 type class 启发的 OCaml 语言扩展，用于特设多态（ad-hoc polymorphism）。它基于类型驱动的隐式模块参数，可直接展开为 OCaml 的一等 functor，因此天然支持继承、实例约束、constructor class 和 associated types 等其他语言中的特性。

HN 为什么提它

HN 上的人把它当作在 ML 模块的灵活性和 type class 的便利重载之间取得务实平衡的方案，并称论文本身好读、不空谈理论。
