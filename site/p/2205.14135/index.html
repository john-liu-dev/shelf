自注意力的时间和显存复杂度随序列长度呈二次增长，近似注意力方法往往牺牲质量却没有换来实际加速。论文认为缺失的原则是让注意力算法具备 IO 感知，即考虑 GPU 各级内存之间的读写，并提出 FlashAttention：用分块（tiling）减少 GPU 高带宽显存（HBM）与片上 SRAM 之间的读写次数，经分析需要的 HBM 访问比标准注意力更少，并在一定范围的 SRAM 大小下最优。它还可扩展成块稀疏注意力。训练上，BERT-large 比 MLPerf 1.1 记录端到端快 15%，GPT-2 快 3 倍，长程竞技场快 2.4 倍，并带来更长上下文和更高质量。

HN 为什么提它

评论者把它当作缓解注意力二次方成本的可行方案和现代 LLM 训练的常用组件来引用，也有人指出其主要局限是需要针对每种 GPU 架构手写 CUDA 内核。

方法难度 4 / 5约 60 分钟经得起时间
