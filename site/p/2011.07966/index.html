法国所得税由公共财政总局（DGFiP）用一套 1990 年设计的遗留自定义语言和编译器来计算，越来越难维护。作者重构了这套基础设施，提出开源编译工具链 Mlang：它基于逆向工程得到的形式化语义，并用 DGFiP 的私有测试集充分验证；消除了手写的 C 语言补丁，可编译到 Python，并支持多种插桩分析。DGFiP 已正式过渡到使用 Mlang 作为生产系统。

HN 为什么提它

评论者把它当作「把法律条文变成可执行代码」的案例，借它讨论法律规则的可计算性、DSL，以及编译到 Python 后衍生出的 OpenFisca 等项目。
