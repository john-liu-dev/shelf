论文受 Igarashi、Pierce 和 Wadler 的 Featherweight Java 启发，给出 Go 泛型的设计与形式化。Java 的子类型是名义的、泛型靠擦除实现，而 Go 的子类型是结构化的、泛型采用单态化（monomorphisation）；作者是最早对单态化做形式化的工作之一，该设计还支持解决表达式问题（The Expression Problem）。

HN 为什么提它

评论者在讨论 Go 泛型时引用它，说明 Go 泛型有形式化基础，并常借此提到 Philip Wadler 受 Go 团队邀请参与设计的经过。
