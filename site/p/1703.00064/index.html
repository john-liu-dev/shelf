针对 WiFi 中负载下因过度排队（bufferbloat）造成的延迟，以及 802.11 性能反常这两大问题，设计了新的无线队列方案，并基于它实现了无需改动客户端的接入点空口时间公平调度器。理论模型和测试床实验显示，负载下延迟降低一个数量级，多站点吞吐大幅提升，TCP 与下行 UDP 流量的空口时间接近完美公平。其生产级实现已被 Linux 主线内核接受。

HN 为什么提它

评论者把它视为让 WiFi 路由器抗 bufferbloat 的论文依据，并提到该方案已在 LEDE 等 Linux 系统中可用，许多 WiFi 设备默认采用类似 fq_codel 的队列。
