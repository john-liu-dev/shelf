Sneaked references: Cooked reference metadata inflate citation counts

揭露在 DOI 注册元数据中偷塞参考文献以刷高引用数的做法

论文报告了一种未被记录的操纵引用数的方法：把论文里并未出现的“sneaked 参考文献”登记进其元数据。这利用了出版商、Crossref 元数据注册机构、数字图书馆和文献计量平台之间的信任关系。作者以某出版商的三种期刊为案例，至少发现 9%（5,978/65,836）的被塞入参考文献，主要使两位作者受益；同时发现被研究的文献计量平台至少漏索引了 56% 的 HTML 版本所列参考文献（“丢失”的参考文献）。全球文献中的规模仍然未知，需要进一步调查。

HN 为什么提它

评论者引用它作为科学出版也难逃逐利操纵的例子，并讨论这类造假更可能出自期刊编辑而非作者，以及有没有人核对参考文献是否真的出现在正文中。
