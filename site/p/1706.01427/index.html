关系推理是通用智能的核心，却很难让神经网络学会。论文介绍关系网络（Relation Networks，RN）这一即插即用的简单模块，并在三类任务上测试：视觉问答（CLEVR 数据集，达到当时最佳并超越人类）、基于文本的 bAbI 问答，以及动态物理系统推理。借助 Sort-of-CLEVR 数据集，作者还表明强大的卷积网络本身不具备通用的关系推理能力，加上 RN 后才获得。

HN 为什么提它

HN 上的人把它当作 DeepMind 关系推理模块的出处，作为样本效率进步和神经网络能回答场景问题的例子，也出现在论文阅读清单中。

方法难度 3 / 5约 40 分钟有时效性
读之前最好知道
1卷积神经网络（CNN）
2视觉问答（VQA）与 CLEVR 数据集
3LSTM
4关系推理与对象表示

学习路径

读这篇之前，按顺序读书架上的 6 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径先看记忆网络与 bAbI 这条问答推理主线，再看动态记忆网络和视觉推理的程序式方法，最后读关系网络如何用一个简单模块在 CLEVR 与 bAbI 上取得好成绩。

    Memory Networks
    Memory Networks记忆网络 · 2014

    带外部记忆的推理模型的起点，目标论文在文本问答上与此类方法对比。

    读记忆读写与问答推理的基本框架。

  2. 2
    End-To-End Memory Networks
    End-To-End Memory Networks端到端记忆网络 · 2015

    可端到端训练的多跳记忆网络，是 bAbI 上的重要基线。

    读多跳注意力读取记忆的机制。

  3. 3
    Towards AI-Complete Question Answering
    Towards AI-Complete Question Answering: A Set of Prerequisite Toy Tasks迈向 AI 完备的问答：一组前置玩具任务 · 2015

    关系网络要评测的 bAbI 任务集来自这里。

    读各任务类型与评测方式，尤其是需要推理的任务。

  4. 4
    Ask Me Anything
    Ask Me Anything: Dynamic Memory Networks for Natural Language ProcessingAsk Me Anything：面向自然语言处理的动态记忆网络 · 2015

    动态记忆网络，在 bAbI 上的强基线。

    读情景记忆与迭代注意力，与关系网络的做法对比。

  5. 5
    Dynamic Memory Networks for Visual and Textual Question Answering
    Dynamic Memory Networks for Visual and Textual Question Answering2016

    把动态记忆网络扩展到视觉问答，与目标论文在视觉任务上对应。

    读视觉输入如何接入记忆模块。

  6. 6
    Inferring and Executing Programs for Visual Reasoning
    Inferring and Executing Programs for Visual Reasoning2017

    同期在 CLEVR 上的程序式方法，是对照关系网络端到端方案的另一条路线。

    读先生成程序再执行的流程，与关系网络的简单模块对比。
