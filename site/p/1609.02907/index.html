论文提出一种可扩展的图半监督学习方法：直接在图上运行的卷积神经网络变体，其结构由谱图卷积的局部一阶近似推导而来。模型计算量随图的边数线性增长，隐层同时编码局部图结构和节点特征。在引文网络和知识图谱数据集上，它显著优于相关方法。

HN 为什么提它

HN 上有人把它列为值得从头实现的“由易到难”GNN 论文之一，也有人在讨论树结构数据时提到它，作为图卷积层的代表。

奠基之作难度 3 / 5约 40 分钟经得起时间
读之前最好知道
1图论与邻接矩阵
2卷积神经网络
3谱图理论与图拉普拉斯（graph Laplacian）
4半监督学习

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径先看词向量与基于随机游走的节点嵌入（DeepWalk）这条图表示学习的前史，再补上残差连接，最后读 GCN 如何用一阶谱近似直接在图上做卷积。

  1. 1
    Efficient Estimation of Word Representations in Vector Space
    Efficient Estimation of Word Representations in Vector Space向量空间中词表示的高效估计 · 2013

    word2vec 的 skip-gram 是 DeepWalk 的方法来源，也是「学习表示」思路的起点。

    读skip-gram 目标与词向量的含义；先抓概念，不必深究训练细节。

  2. 2
    DeepWalk
    DeepWalk: Online Learning of Social Representations2014

    DeepWalk 把随机游走当作句子，用 skip-gram 学节点嵌入，是 GCN 要对比的基线方法。

    读随机游走生成节点序列再套用 skip-gram 的流程，以及它的局限（不使用节点特征）。

  3. 3
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    GCN 在加深层数的讨论里借用了残差连接。

    读残差块 y = F(x) + x 的基本形式，为什么能让更深的网络可训练。

  4. 4
    Semi-Supervised Classification with Graph Convolutional Networks
    Semi-Supervised Classification with Graph Convolutional Networks基于图卷积网络的半监督分类 · 2016 · 就是这篇

    以谱图卷积的局部一阶近似推出简单高效的 GCN 层，在引文网络上做半监督节点分类。

    读从谱卷积到 GCN 传播规则的推导，以及带重归一化技巧的层公式。
