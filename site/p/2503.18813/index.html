针对 LLM agent 处理不可信数据时易受提示注入攻击的问题，提出 CaMeL：在 LLM 外围建立一层保护性系统，即使底层模型易受攻击也能保证安全。它显式从可信的用户查询中提取控制流和数据流，使 LLM 取回的不可信数据无法影响程序流程，并用能力（capability）机制在调用工具时执行安全策略，防止私有数据经未授权数据流外泄。在 AgentDojo 上，CaMeL 以可证明的安全性解决 77% 的任务，无防御系统为 84%。

HN 为什么提它

评论者认为它是目前最可信的提示注入解法之一：不依赖 AI 去检测攻击，而是靠架构上隔离不可信数据，常被当作 agent 安全设计的参考模型。
