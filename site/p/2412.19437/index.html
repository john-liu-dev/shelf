DeepSeek-V3 是总参数 671B、每个 token 激活 37B 的混合专家（MoE）语言模型，采用经 DeepSeek-V2 验证的多头潜在注意力（MLA）和 DeepSeekMoE 架构，并首创无辅助损失的负载均衡策略，同时使用多 token 预测训练目标。模型在 14.8 万亿 token 上预训练，再经监督微调与强化学习。评测显示它超过其他开源模型、与领先闭源模型相当；完整训练只需 2.788M H800 GPU 小时，且训练过程稳定，没有不可恢复的损失尖峰或回滚。

评论者多是为查证而引用它：约 560 万美元（2.788M H800 GPU 小时）的训练成本说法、DualPipe 与通信优化、PTX 的实际使用范围，以及 256 个专家、每层路由 8 个的 MoE 结构细节。
