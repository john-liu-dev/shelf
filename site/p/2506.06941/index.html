论文用可精确调节复杂度的谜题环境评估大型推理模型（LRM），不仅看最终答案，也分析推理轨迹。实验显示 LRM 在超过某一复杂度后准确率完全崩溃，推理努力在问题变难时先升后降，尽管仍有 token 预算。对比同等推理算力下的普通 LLM，出现三种区间：低复杂度时普通模型更好，中等复杂度时 LRM 占优，高复杂度时两者都崩溃；LRM 在精确计算上也有局限，不会使用显式算法，在不同规模上推理不一致。

HN 为什么提它

HN 评论者引它支持“推理模型只是更高层次的模式匹配、到复杂度极限就失效”的观点，也有人批评如汉诺塔这类题的失败其实源于输出 token 上限，而不是推理能力。
