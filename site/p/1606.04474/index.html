论文指出优化算法至今仍靠手工设计，于是把优化算法的设计转化为一个学习问题，让算法自动利用问题的结构，用 LSTM 来实现学出来的优化器。这些学出来的优化器在其训练任务上优于通用的手工设计方法，也能泛化到结构相似的新任务，实验包括简单凸问题、训练神经网络和神经风格迁移。

学习路径

读这篇之前，按顺序读书架上的 2 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

只有少数候选真正相关：先了解 Adam 这类手工设计的优化器，再看神经风格迁移这个实验任务，就能读懂论文如何让 LSTM 学成优化器并与它们对比。

  1. 1
    Adam
    Adam: A Method for Stochastic OptimizationAdam：一种随机优化方法 · 2014

    论文要被取代的正是 Adam 这类手工设计的优化器，实验里也拿它做基线。

    读一阶、二阶矩估计和更新规则的概念；理解手工优化器编码了哪些先验。

  2. 2
    A Neural Algorithm of Artistic Style
    A Neural Algorithm of Artistic Style艺术风格的神经算法 · 2015

    论文的一个实验任务是用学到的优化器做神经风格迁移，需要先懂这个任务。

    读内容损失与风格损失（Gram 矩阵）的定义；只需要明白优化的是什么目标。

  3. 3
    Learning to learn by gradient descent by gradient descent
    Learning to learn by gradient descent by gradient descent用梯度下降学习梯度下降 · 2016 · 就是这篇

    目标论文：把优化器设计转为学习问题，用 LSTM 当优化器并用梯度下降训练它。

    读优化器的输入是梯度、输出是参数更新，以及按轨迹累计损失来训练；看二次函数、MNIST 和风格迁移的泛化结果。
