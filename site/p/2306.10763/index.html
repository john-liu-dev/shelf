代码语言模型缺乏对仓库中其他位置定义的类型、API 的了解，容易编造不存在的调用。论文提出监视器引导解码（MGD）：解码时由监视器借助静态分析约束输出，例如保证对象解引用类型一致。在作者构建的 Java 仓库级方法补全数据集 PragmaticCode 上，MGD 在不同规模模型上都提高了编译率和与真值的一致性，小模型 SantaCoder-1.1B 加上 MGD 后超过大得多的 text-davinci-003；方法还可推广到 C#、Rust 及更丰富的语义约束。

HN 为什么提它

HN 评论者把它当作“在推理时接入静态分析，让生成的代码不止语法正确、没有幻觉的解引用”的代表性工作来引用。
