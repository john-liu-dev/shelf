GPipe 是一个流水线并行库，可以把任何能表示为层序列的网络切成多段放在不同加速器上，并通过新颖的批次拆分流水线算法获得近乎线性的加速。论文展示了训练 5.57 亿参数的 AmoebaNet，在 ImageNet-2012 上达到 84.4% 的 top-1 精度，以及训练一个 60 亿参数、128 层、覆盖 100 多种语言的 Transformer，翻译质量优于所有双语模型。

HN 为什么提它

评论者既拿它当 ImageNet 当时最优结果的出处，也把它列进机器学习论文阅读清单，作为大模型并行训练的代表工作。

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先了解数据并行、模型并行的传统做法，以及 GPipe 要扩展的那类大模型，再读流水线并行如何组合它们。

  1. 1
    One weird trick for parallelizing convolutional neural networks
    One weird trick for parallelizing convolutional neural networks并行化卷积神经网络的一个古怪窍门 · 2014

    给出数据并行与模型并行的经典划分，是并行训练的背景。

    读抓卷积层数据并行、全连接层模型并行的取舍；理解通信代价。

  2. 2
    Mesh-TensorFlow
    Mesh-TensorFlow: Deep Learning for Supercomputers2018

    同期的另一种模型并行方案，可与流水线并行对比。

    读抓张量按维度切分到多设备的思路，对比 GPipe 按层切分。

  3. 3
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    GPipe 要扩展的典型图像网络之一，也说明加深加宽带来的收益。

    读了解残差网络的层序列结构，GPipe 只要求网络可表示为层的序列。

  4. 4
    Learning Transferable Architectures for Scalable Image Recognition
    Learning Transferable Architectures for Scalable Image Recognition学习可迁移的架构以实现可扩展的图像识别（NASNet） · 2017

    GPipe 的图像实验网络（AmoebaNet）来自 NAS 搜索空间。

    读只需知道搜出的卷积单元如何堆叠成大网络，不必看搜索算法。

  5. 5
    Attention Is All You Need
    Attention Is All You Need注意力就是你所需要的一切 · 2017

    GPipe 在 Transformer 上做了机器翻译扩展实验。

    读抓编码器-解码器层的堆叠结构，看清它为何适合按层切分。

  6. 6
    GPipe
    GPipe: Efficient Training of Giant Neural Networks using Pipeline ParallelismGPipe：用流水线并行高效训练巨型神经网络 · 2018 · 就是这篇

    按层切分并流水线化，在多块加速器上近线性扩展巨型模型。

    读抓微批次切分与重计算如何降低流水线空泡和内存占用。
