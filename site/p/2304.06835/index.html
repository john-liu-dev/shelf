提出一种高性能、与厂商无关的方法，在 GPU 上大规模并行求解常微分方程（ODE）和随机微分方程（SDE）的集合，集成进 Julia 的 DifferentialEquations.jl，用户无需改代码即可获得 GPU 加速。性能与手工优化的 CUDA-C++ 核函数相当，比 JAX 和 PyTorch 中的向量化映射（vmap）方法快 20–100 倍，并在 NVIDIA、AMD、Intel 和 Apple GPU 上验证了可移植性，还可与 MPI 组合做多 GPU 分布式计算。求解器功能完整，支持事件处理、自动微分和经 GPU 纹理内存引入数据集，已开源为 DiffEqGPU.jl。

HN 为什么提它

作者和评论者用它说明基于核函数的 ODE 集合求解比 PyTorch、JAX 快 20–100 倍，并证明这类跨 GPU 厂商的求解器已经存在、有人在用。

方法难度 4 / 5约 50 分钟经得起时间
