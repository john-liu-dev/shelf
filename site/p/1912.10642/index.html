这份最初用作范畴论课程的讲义适合想从零学习范畴论且有科学头脑的读者，只假定读者学过线性代数，所有概念都用基本群论、图论、概率等非专门领域的具体例子来解释。讲义特别强调 Yoneda 引理及其意义（含直观解释、详细证明与具体例子），详细讨论范畴与有向多重图的关系，并把单子与余单子放在同等地位处理。作者说该作品经全面修订扩充后已成书，并增加了关于幺半范畴的一节。

学习路径

读这篇之前，按顺序读书架上的 2 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径帮我用不同风格的材料补充范畴论入门的直觉：串图计算和应用范畴论的教材，再读以基础数学例子讲授的讲义。

  1. 1
    Category Theory Using String Diagrams
    Category Theory Using String Diagrams2014

    它用串图（string diagrams）讲范畴论，可作为直观的补充视角。

    读范畴、函子、自然变换的图形化表示；先抓直觉，不必深究证明。

  2. 2
    Seven Sketches in Compositionality
    Seven Sketches in Compositionality: An Invitation to Applied Category Theory组合性七篇素描：应用范畴论邀请 · 2018

    它用数据库、电路等应用实例入门范畴论，与目标论文用基础数学例子的思路互补。

    读前几章的序、范畴与函子的实例；对照目标论文的例子。

  3. 3
    Notes on Category Theory with examples from basic mathematics
    Notes on Category Theory with examples from basic mathematics范畴论笔记：以基础数学为例 · 2019 · 就是这篇

    目标论文：以基础数学为例讲范畴论的讲义。

    读从线性代数、群论、图论的例子出发，逐步读范畴、函子、自然变换与泛性质。
