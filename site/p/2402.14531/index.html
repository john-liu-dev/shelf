论文研究提示中的礼貌程度对大语言模型性能的影响，在英语、汉语和日语任务上进行评估，出发点是 LLM 可能映射人类的交流特征。作者观察到不礼貌的提示往往导致较差的表现，但过度礼貌也并不保证更好的结果；最佳礼貌程度因语言而异，说明 LLM 不仅反映人类行为，还会受语言和文化背景影响。作者据此强调跨文化自然语言处理和 LLM 使用中需要考虑礼貌因素。

HN 为什么提它

HN 上的人在讨论对 LLM 要不要客气时引用它，作为提示礼貌程度确实会改变模型表现的证据，同时也有人提醒这是较旧的研究、不知是否适用于新模型。
