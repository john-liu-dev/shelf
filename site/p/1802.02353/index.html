学习路径

读这篇之前，按顺序读书架上的 6 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先看序列输出、可微分计算机和程序归纳语言这些基础，再看 DeepCoder 与 Seq2SQL 等神经程序合成实例，之后读综述的整体脉络。

  1. 1
    Pointer Networks
    Pointer Networks指针网络（Pointer Networks） · 2015

    指针网络让输出直接指向输入位置，是许多神经程序合成模型的组成部分。

    读用注意力指向输入位置作为输出的机制。

  2. 2
    Learning to Transduce with Unbounded Memory
    Learning to Transduce with Unbounded Memory学习使用无界记忆进行序列转换 · 2015

    它给循环网络加上可微的栈与队列记忆，是神经程序归纳的重要路线。

    读可微栈、队列和双端队列的设计思路。

  3. 3
    TerpreT
    TerpreT: A Probabilistic Programming Language for Program InductionTerpreT：用于程序归纳的概率编程语言 · 2016

    TerpreT 把程序归纳问题放到统一语言里比较不同推断方法，帮助理解可微与离散两类路线。

    读程序归纳问题的形式化，以及梯度下降与离散搜索等推断方式的比较。

  4. 4
    Programming with a Differentiable Forth Interpreter
    Programming with a Differentiable Forth Interpreter用可微分的 Forth 解释器编程 · 2016

    它用可微分的 Forth 解释器，让程序草图中的空位由数据学习，是可微分程序合成的代表。

    读程序草图与可微解释器的设计。

  5. 5
    DeepCoder
    DeepCoder: Learning to Write ProgramsDeepCoder：学习编写程序 · 2016

    DeepCoder 用神经网络指导程序搜索，是神经与符号搜索结合的代表。

    读领域专用语言与从输入输出示例预测程序属性的做法。

  6. 6
    Seq2SQL
    Seq2SQL: Generating Structured Queries from Natural Language using Reinforcement Learning2017

    Seq2SQL 把自然语言转成结构化查询，是语义解析方向的程序合成例子。

    读利用 SQL 结构分解输出，以及用强化学习优化执行结果。

  7. 7
    Recent Advances in Neural Program Synthesis
    Recent Advances in Neural Program Synthesis神经程序合成的最新进展 · 2018 · 就是这篇

    在这些具体模型的基础上，看综述如何梳理程序合成与程序归纳的问题和模型演变。

    读程序合成与程序归纳的区别、各类模型的分类与未来方向。
