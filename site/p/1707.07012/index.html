为了避免在大数据集上直接搜索网络架构的高昂代价，作者在小数据集上搜索架构构建块，再迁移到大数据集。关键贡献是设计了可迁移的新搜索空间（NASNet 搜索空间）：在 CIFAR-10 上搜索最佳卷积单元（cell），再堆叠更多副本构成用于 ImageNet 的 NASNet 架构，并提出正则化方法 ScheduledDropPath。NASNet 在 CIFAR-10 上错误率为 2.4%，在 ImageNet 上达到 82.7% top-1 和 96.2% top-5，比当时最好的人工设计架构 top-1 高 1.2%，FLOPS 少 90 亿；其特征用于 Faster-RCNN 在 COCO 上达到 43.1% mAP。

HN 为什么提它

HN 上的人把它当作神经架构搜索的实例，用来说明自动搜索可发现计算量更少的卷积网络，同时也有人提醒现代架构已明显更好。

方法难度 3 / 5约 50 分钟经得起时间
读之前最好知道
1卷积神经网络与图像分类
2神经架构搜索（neural architecture search）
3强化学习中的控制器（controller RNN）
4正则化与 dropout

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先熟悉图像分类网络的主流模块（Inception、ResNet、DenseNet），再看用强化学习搜索架构的早期方法，最后读 NASNet 如何设计可迁移的搜索空间。

    Going Deeper with Convolutions
    Going Deeper with Convolutions用卷积走得更深 · 2014

    NASNet 的 cell 内部有多个并行分支，思路与 Inception 相似。

    读多分支模块的结构。

  2. 2
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    NASNet 的 cell 采用跳连，并与 ResNet 作对比。

    读残差连接的结构。

  3. 3
    Densely Connected Convolutional Networks
    Densely Connected Convolutional Networks密集连接卷积网络（DenseNet） · 2016

    密集连接是手工设计的强基线，也是搜索空间中连接方式的来源之一。

    读特征拼接的连接模式。

  4. 4
    Neural Architecture Search with Reinforcement Learning
    Neural Architecture Search with Reinforcement Learning用强化学习搜索神经网络架构 · 2016

    NASNet 的搜索方法直接沿用这篇的 RNN 控制器与强化学习训练，只是改变了搜索空间。

    读控制器如何采样架构、用验证精度作奖励；对比原文直接搜整网的代价。

    Designing Neural Network Architectures using Reinforcement Learning用强化学习设计神经网络架构 · 2016

    读Q 学习逐层选择的搜索方式。

  6. 6
    Learning Transferable Architectures for Scalable Image Recognition
    Learning Transferable Architectures for Scalable Image Recognition学习可迁移的架构以实现可扩展的图像识别（NASNet） · 2017 · 就是这篇

    目标论文：在小数据集上搜出卷积 cell，再堆叠迁移到 ImageNet，关键是新的搜索空间。
