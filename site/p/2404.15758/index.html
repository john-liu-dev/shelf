论文问思维链带来的提升，究竟来自类似人类的任务分解，还是来自额外 token 提供的更多计算。作者表明 Transformer 可以用无意义的填充 token（如“......”）代替思维链，解决两个没有中间 token 时解不了的困难算法任务，但学会使用填充 token 很困难，需要特定的密集监督才能收敛。论文还用一阶公式的量词深度刻画了填充 token 有用的问题类别，并指出这引发对 LLM 进行不可审计、与可见思维链脱节的隐藏计算的担忧。
