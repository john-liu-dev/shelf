研究给定算力预算下 Transformer 语言模型的最优参数量与训练 token 数。通过训练 400 多个模型，发现当时的大模型都训练不足：计算最优时模型大小每翻一倍，训练 token 也应翻一倍。据此训练的 Chinchilla 与 Gopher 算力相同，参数为 70B、数据多 4 倍，在大量下游任务上明显优于 Gopher、GPT-3 等更大的模型，在 MMLU 上平均准确率达 67.5%。

HN 为什么提它

评论者把它当作训练数据量与参数量关系的标准出处，用来说明大多数大模型训练 token 不足，小模型喂更多数据可以胜过更大的模型（如 70B 胜过 175B 的 GPT-3）。
