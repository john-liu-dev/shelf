论文认为无服务器云计算承担了几乎所有系统管理工作，大幅简化云编程，其意义类似于从汇编语言到高级语言的转变。文章回顾云计算简史并核对 2009 年伯克利云计算报告的预测，说明无服务器的动机，介绍目前触及其极限的应用，并列出要充分发挥潜力所需克服的障碍与研究机会，预测这些问题可以解决，无服务器计算将主导云计算的未来。

  1. 1
    Occupy the Cloud
    Occupy the Cloud: Distributed Computing for the 99%2017

    论证无服务器可让普通用户使用分布式计算，是目标论文提到的动机之一。

    读作者提出的愿景，以及现有云服务对普通用户的使用门槛。

  2. 2
    numpywren
    numpywren: serverless linear algebra2018

    numpywren 在无服务器上做线性代数，是目标论文讨论其应用边界时的实例。

    读把大规模线性代数拆成无状态任务的做法，以及与传统集群的性能和成本对比。

  3. 3
    Cloud Programming Simplified
    Cloud Programming Simplified: A Berkeley View on Serverless Computing简化云编程：伯克利对无服务器计算的看法 · 2019 · 就是这篇

    回顾云计算历史，论证无服务器将成为云计算的主流形态，并指出现有局限。

    读无服务器的定义、与 2009 年 Berkeley View 的对照，以及对当前限制和未来方向的讨论。
