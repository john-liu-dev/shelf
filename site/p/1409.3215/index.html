论文提出一种对序列结构几乎不做假设的端到端序列学习方法：用多层 LSTM 把输入序列映射成固定维度的向量，再用另一个深度 LSTM 从该向量解码出目标序列。在 WMT'14 英法翻译上，LSTM 的 BLEU 为 34.8，高于短语式 SMT 系统的 33.3；用 LSTM 对 SMT 的 1000 个候选重排后升到 36.5。把源句的词序反转（目标句不反转）会明显改善效果，因为这引入了许多源与目标之间的短期依赖，使优化更容易。

学习路径

读这篇之前，按顺序读书架上的 2 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径帮你先理解用 LSTM 逐步生成序列，以及循环网络做编码器-解码器的早期尝试，再读 seq2seq。

  1. 1
    Generating Sequences With Recurrent Neural Networks
    Generating Sequences With Recurrent Neural Networks用循环神经网络生成序列 · 2013

    seq2seq 的解码器就是 LSTM 逐步预测下一个符号的生成过程，来自这里的做法。

    读LSTM 如何逐点预测并生成序列；next-step prediction 的训练方式。

  2. 2
    Learning Phrase Representations using RNN Encoder-Decoder for Statistical Machine Translation
    Learning Phrase Representations using RNN Encoder-Decoder for Statistical Machine Translation2014

    几乎同期提出的 RNN 编码器-解码器，把输入压成定长向量再解码，与 seq2seq 思路平行。

    读编码器-解码器结构及其用于短语表示的做法；与 seq2seq 对比二者的差别。

  3. 3
    Sequence to Sequence Learning with Neural Networks
    Sequence to Sequence Learning with Neural Networks用神经网络进行序列到序列学习 · 2014 · 就是这篇

    用深层 LSTM 编码再解码，把端到端序列到序列学习推到机器翻译上。

    读整体模型结构、反转源句的技巧，以及翻译任务的结果。
