论文证明，由标准梯度下降训练的深度网络在数学上近似等价于核机器，即一种直接记住数据、通过相似度函数（核）做预测的学习方法。这意味着网络权重实际上是训练样本的叠加，网络架构则把目标函数的知识编码进核里，作者认为这会增强对深度网络权重的可解释性，并带来更好的学习算法。

HN 为什么提它

评论者在讨论深度学习是否只是插值或记忆时引用它，说明神经网络近似 kNN 或核机器，但也有人认为它的结论被夸大了。

学习路径

读这篇之前，按顺序读书架上的 2 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先看大网络为何能拟合随机标签，再读神经正切核如何把无限宽网络的训练化为核方法，之后就能理解 Domingos 把任意梯度下降模型都描述成核机器的论证。

  1. 1
    Understanding deep learning requires rethinking generalization
    Understanding deep learning requires rethinking generalization理解深度学习需要重新思考泛化 · 2016

    它显示大网络能记住随机标签，引出对深度网络究竟学到表示还是记忆数据的疑问。

    读随机标签实验和对传统泛化理论的挑战；不必看所有正则化消融。

  2. 2
    Neural Tangent Kernel
    Neural Tangent Kernel: Convergence and Generalization in Neural Networks神经正切核：神经网络的收敛与泛化 · 2018

    NTK 说明无限宽网络的训练等价于固定核上的核梯度下降，是目标论文把这一观点推广到所有模型的前驱。

    读神经正切核的定义，以及训练动态在核空间中的描述；公式推导可略读。

  3. 3
    Every Model Learned by Gradient Descent Is Approximately a Kernel Machine
    Every Model Learned by Gradient Descent Is Approximately a Kernel Machine梯度下降学到的每个模型都近似于核机器 · 2020 · 就是这篇

    目标论文：证明梯度下降学到的模型近似为核机器，并解读其权重为训练样本的叠加。

    读路径核（path kernel）的定义与主定理，以及对深度学习为何不是在学新表示的讨论。
