作者提出并实现了 rr，一个完全运行在用户态、使用现成硬件、编译器、运行时和操作系统的记录与回放系统，避免了录制整机虚拟机、修改内核或全面插桩等做法。只要 CPU 和操作系统满足若干不太显然的约束（现代 Intel CPU 与 Linux 恰好满足），rr 就能以较低开销记录并回放低并行度的真实负载，并已成为实际使用的逆向执行调试器。文中还给出性能评估，并指出对硬件和操作系统设计的要求。

HN 为什么提它

每当有人问 rr 如何让多线程程序可确定地重放、如何只记录外部输入、为何开销很低，评论者就指向这份技术报告作为权威解释。

方法难度 4 / 5约 70 分钟经得起时间

4调试器基础（断点、反向调试）
5确定性重放（deterministic replay）
