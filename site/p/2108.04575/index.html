论文提出攻击 AMD SEV 保护的虚拟机的新办法：针对安全处理器 AMD-SP 做电压毛刺（voltage glitching）攻击，能在目前市面上所有支持 SEV 的微架构（Zen 1、Zen 2、Zen 3）的 AMD-SP 上执行自定义负载。借此可部署自定义 SEV 固件、解密虚拟机内存，并提取 CPU 的背书密钥来伪造证明报告或冒充合法迁移目标。作者还逆向了 SEV-SNP 引入的 VCEK 机制，并展示如何为任意固件版本推导出有效的 VCEK，据此证明在现有 CPU 上 SEV 无法防住云环境中如恶意管理员这类内部攻击者。

HN 为什么提它

HN 评论者引用它来说明机密计算（如 AMD SEV）无法抵御物理攻击，其密钥提取可以伪造硬件证明，据称还被用来破解特斯拉。
