借鉴 Rust 借用检查器，为 Ada 子集 SPARK 引入可验证的指针

在演绎式软件验证中，指针别名是主要难题。论文为面向关键任务软件形式验证的 Ada 子集 SPARK 引入指针，方案基于受 Rust 借用检查器和仿射类型启发的静态别名分析，强制“并发读、独占写”原则，已在 GNAT Ada 编译器中实现，并在包括真实应用片段在内的难例上测试，只需对源码做少量改动。报告还对 SPARK 的小型版本给出分析规则的形式化表述并证明其可靠性，讨论了实现和案例，并与 Rust 做了比较。
