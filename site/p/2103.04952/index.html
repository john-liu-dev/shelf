论文想确认缓存侧信道攻击到底依赖哪些 JavaScript 特性，以评估靠禁用或限制这些特性来防御的做法是否有效。作者构造了对 JavaScript 依赖逐步降低的一系列攻击，最终做出首个完全由 CSS 和 HTML 构成、脚本被完全禁用时仍有效的浏览器侧信道攻击。避免 JavaScript 特性还让技术与架构无关，在 Intel Core、AMD Ryzen、Samsung Exynos 和 Apple M1 上都能做微架构网站指纹识别。在 Tor 浏览器、DeterFox 和 Chrome Zero 等加固环境里，没有一种能完全防住这些攻击。

HN 为什么提它

HN 评论者提到它是因为其浏览器侧信道指纹识别技术虽然不太实用，却很有意思。
