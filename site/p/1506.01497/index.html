论文提出区域建议网络（RPN），它与检测网络共享整幅图像的卷积特征，因此区域建议几乎不再耗时。RPN 是全卷积网络，在每个位置同时预测目标边界和目标性得分，可端到端训练，其产生的建议交给 Fast R-CNN 做检测，二者合并后共享卷积特征成为一个统一网络。在 VGG-16 上，整个检测系统在 GPU 上达到 5fps，每张图只用 300 个建议，在 PASCAL VOC 2007、2012 和 MS COCO 上达到当时最优的精度。

HN 为什么提它

有人问如何做目标检测或图像识别时，评论者把 Faster R-CNN（以及 YOLO）作为取代传统 HOG+SVM 的推荐方案，也称它是几乎没什么数学却很巧妙的论文。

方法难度 3 / 5约 45 分钟经得起时间
读之前最好知道

4区域建议（region proposal）与锚框

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径帮你建立 Faster R-CNN 使用的卷积特征提取网络背景：可视化理解卷积特征、VGG 以及残差网络。

  1. 1
    Visualizing and Understanding Convolutional Networks
    Visualizing and Understanding Convolutional Networks卷积网络的可视化与理解 · 2013

    论文最初用 ZF 网络作为特征提取骨干，并说明卷积特征为什么适合共享。

    读读各层特征的可视化，理解卷积特征图保留空间信息的含义。

  2. 2
    Very Deep Convolutional Networks for Large-Scale Image Recognition
    Very Deep Convolutional Networks for Large-Scale Image Recognition面向大规模图像识别的极深卷积网络 · 2014

    VGG 是论文里的另一个骨干网络，检测精度主要靠它提升。

    读抓 3x3 小卷积堆叠的结构和 16 层配置。

  3. 3
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    残差网络可作为更强的骨干，替换后检测效果明显提升。

    读读残差块的结构，理解为何更深的骨干能带来更好的特征。

  4. 4
    Faster R-CNN
    Faster R-CNN: Towards Real-Time Object Detection with Region Proposal NetworksFaster R-CNN：用区域建议网络实现实时目标检测 · 2015 · 就是这篇

    引入与检测网络共享特征的区域建议网络，使候选框近乎零成本。

    读重点读区域建议网络（RPN）的锚框（anchor）设计，以及与 Fast R-CNN 交替训练共享特征的做法。
