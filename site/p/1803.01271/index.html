论文在一系列常用序列建模基准上系统比较通用的卷积架构与循环架构。结果显示，一个简单的卷积架构（TCN）在多种任务和数据集上优于 LSTM 等典型循环网络，并且有效记忆更长。作者据此主张，序列建模不应默认选循环网络，卷积网络应作为自然的起点，并公开了代码。

HN 为什么提它

HN 评论者引用它来支持「多数序列任务用 TCN / 一维卷积就够，往往比 LSTM 更快、效果更好」这一实用建议。

学习路径

读这篇之前，按顺序读书架上的 4 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径帮你理解 TCN 用到的残差连接与膨胀因果卷积，以及它要对比的卷积序列模型和强循环基线。

  1. 1
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    TCN 的基本模块借用了残差块来训练深层卷积序列网络。

    读残差块 y = x + F(x) 的结构与恒等跳连；不必看检测与分类实验。

  2. 2
    WaveNet
    WaveNet: A Generative Model for Raw AudioWaveNet：原始音频的生成模型 · 2016

    WaveNet 的膨胀因果卷积（dilated causal convolution）是 TCN 的核心做法。

    读因果卷积与膨胀系数指数增长带来的感受野；跳过音频合成细节。

  3. 3
    Neural Machine Translation in Linear Time
    Neural Machine Translation in Linear Time2016

    ByteNet 用卷积做序列到序列翻译，是本文所说卷积序列模型的先例。

    读膨胀卷积堆叠的编码器解码器及其线性时间复杂度。

  4. 4
    Regularizing and Optimizing LSTM Language Models
    Regularizing and Optimizing LSTM Language Models2017

    AWD-LSTM 是本文语言建模任务里的强 LSTM 基线，用来对比 TCN。

    读权重丢弃、正则化与优化技巧，理解基线为什么强。

  5. 5
    An Empirical Evaluation of Generic Convolutional and Recurrent Networks for Sequence Modeling
    An Empirical Evaluation of Generic Convolutional and Recurrent Networks for Sequence Modeling通用卷积与循环网络在序列建模上的实证评估 · 2018 · 就是这篇

    目标论文：在一系列标准序列任务上系统比较通用 TCN 与 LSTM、GRU 等循环网络。

    读TCN 结构（因果加膨胀加残差）与各任务对比表；注意其结论的适用范围。
