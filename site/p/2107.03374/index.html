论文介绍 Codex，一个在 GitHub 公开代码上微调的 GPT 模型，其生产版本驱动了 GitHub Copilot，并研究它写 Python 的能力。作者发布了新评测集 HumanEval，用来衡量根据 docstring 合成程序的功能正确性：Codex 解出 28.8% 的题目，GPT-3 为 0%，GPT-J 为 11.4%。每题采样 100 次可解出 70.2%，说明重复采样是产出可用解的有效策略。论文也分析了模型的局限（如长操作链与变量绑定），并讨论了安全、安保与经济方面的影响。

HN 为什么提它

评论者主要用它查证 Copilot 背后 Codex 的数字：HumanEval 上 28.8%、采样 100 次后约 70%，以及它由 GPT-3 家族微调而来；也有人质疑评测集可能已被训练数据污染。
