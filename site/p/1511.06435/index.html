在单机（多线程 CPU 与 Titan X GPU）上，从可扩展性、硬件利用率和速度三方面比较 Caffe、Neon、TensorFlow、Theano、Torch 五个深度学习框架，速度指标包括梯度计算时间和前向时间。结论是 Theano 和 Torch 最易扩展，Torch 在 CPU 上整体最佳，Theano 在 LSTM 的 GPU 训练与部署上最好，而当时 TensorFlow 的性能不具竞争力。
