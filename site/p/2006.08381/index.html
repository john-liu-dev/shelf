提出 DreamCoder，一个通过写程序来解决问题的系统：它为领域概念创建编程语言，并训练神经网络引导在这些语言中的程序搜索。唤醒-睡眠算法交替进行：一边用新的符号抽象扩展语言，一边在想象和回放的问题上训练神经网络。它能解决经典归纳编程任务以及画图、搭场景等创造性任务，并重新发现函数式编程基础、向量代数和牛顿定律、库仑定律。

学习路径

读这篇之前，按顺序读书架上的 2 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

候选里只有两篇和 DreamCoder 的核心思路直接相关：一篇讲类人学习为何需要组合性与程序式表示，一篇讲神经引导的程序搜索。

  1. 1
    Building Machines That Learn and Think Like People
    Building Machines That Learn and Think Like People构建像人一样学习和思考的机器 · 2016

    DreamCoder 的动机来自这里：类人学习靠组合性、因果模型和可复用概念。

    读读组合性（compositionality）与「学会学习」的论述，理解为何要学一套领域概念语言。

  2. 2
    DeepCoder
    DeepCoder: Learning to Write ProgramsDeepCoder：学习编写程序 · 2016

    DreamCoder 的识别网络沿用了神经网络引导程序搜索的思路。

    读抓住用网络预测程序成分来缩小搜索空间的想法，以及基于输入输出示例的程序合成设定。

  3. 3
    DreamCoder
    DreamCoder: Growing generalizable, interpretable knowledge with wake-sleep Bayesian program learningDreamCoder：用唤醒-睡眠贝叶斯程序学习积累可泛化、可解释的知识 · 2020 · 就是这篇

    把程序合成、神经引导搜索与自建语言（库学习）合到唤醒-睡眠框架里。

    读抓 wake-sleep 的三个阶段：搜索程序、抽象出新概念扩充语言、用梦境数据训练识别网络。
