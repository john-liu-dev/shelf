Reformer: The Efficient Transformer

Reformer：高效的 Transformer
Nikita Kitaev, Łukasz Kaiser, Anselm Levskaya · 2020

用局部敏感哈希注意力和可逆层降低 Transformer 的计算与显存

论文提出两项提升 Transformer 效率的技术：用局部敏感哈希（LSH）注意力替代点积注意力，把复杂度由 O(L²) 降到 O(L log L)；并用可逆残差层，使激活只需存储一次而不是 N 次。得到的 Reformer 性能与标准 Transformer 相当，但在长序列上显存占用更小、速度更快。

HN 为什么提它

HN 评论者提到它，一是作为 Transformer 中可逆层节省反向传播内存的先例，二是作为早期次二次稀疏注意力方法的代表来做对比。

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先掌握标准自注意力的 O(L²) 代价，再看稀疏注意力如何处理长序列，最后读 Reformer 的哈希注意力与可逆层。

  1. 1
    Attention Is All You Need
    Attention Is All You Need注意力就是你所需要的一切 · 2017

    Reformer 要改造的就是这里的缩放点积注意力和残差层。

    读缩放点积注意力与多头注意力的计算量；序列长度 L 带来的 L² 开销。

  2. 2
    Generating Wikipedia by Summarizing Long Sequences
    Generating Wikipedia by Summarizing Long Sequences2018

    较早针对长序列改造 Transformer 注意力的工作，说明长序列为何昂贵。

    读只抓住 decoder-only 结构与对注意力做压缩以处理长输入的思路；跳过摘要生成实验。

  3. 3
    Generating Long Sequences with Sparse Transformers
    Generating Long Sequences with Sparse Transformers2019

    Sparse Transformer 用稀疏注意力模式降低复杂度，是 Reformer 的直接对照。

    读稀疏注意力的因子分解模式与它省下的计算；对比固定稀疏模式与 LSH 的自适应分桶。

  4. 4
    Reformer
    Reformer: The Efficient TransformerReformer：高效的 Transformer · 2020 · 就是这篇

    目标论文：用 LSH 注意力把复杂度降到 O(L log L)，并用可逆层省显存。

    读LSH 注意力（哈希分桶、分块）与可逆残差层两部分；弄清各自省的是时间还是显存。
