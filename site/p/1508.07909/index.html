神经机器翻译模型通常使用固定词表，而翻译是开放词表问题。以往通过回退到词典来处理未登录词，论文提出更简单也更有效的做法：把稀有词和未知词编码为子词单元序列，使 NMT 模型具备开放词表翻译能力。其直觉是各类词可以经由比词更小的单元翻译，如专名、复合词、同源词和借词。作者讨论了字符 n-gram 和基于字节对编码（BPE）压缩算法的切分方法，在 WMT 15 的英德、英俄翻译任务上，子词模型相对回退词典基线分别提升 1.1 和 1.3 BLEU。

HN 上的人在讨论 LLM 分词器时把它当作 BPE 子词 token 的原始出处，称其有可读的 Python 示例，也提醒子词 token 从 2015 年起就已在使用。
