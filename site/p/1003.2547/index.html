C Object System（Cos）是一个小型 C 库，实现了 CLOS、Objective-C 等面向对象语言中的高级概念：统一对象模型（类、元类、属性元类）、泛型函数、多方法、委托、属性、异常、契约和闭包。它利用 C 语言的可编程能力扩展语法，把这些概念实现为一等对象，设计目标是简洁、可扩展、可复用、高效和可移植，并针对高效、可移植的消息多分派与多转发做了优化。

HN 为什么提它

HN 评论者把它作为在 C 编译器之上实现面向对象编程的例子推荐，其对象系统受 CLOS 与 Objective-C 启发。
