论文研究 Transformer 如何在推理时处理比训练时更长的序列，先证明只需改变位置表示就能实现外推，但现有方法并不高效。作者提出 ALiBi：不给词嵌入加位置嵌入，而是用与距离成正比的惩罚去偏置查询与键之间的注意力分数。以 1024 长度训练的 13 亿参数模型可外推到 2048，困惑度与在 2048 长度上训练的正弦位置嵌入模型相同，训练还快 11%、省 11% 内存，并在 WikiText-103 上优于多种强位置方法。

HN 为什么提它

讨论长上下文和位置编码时，评论者把 ALiBi 当作许多长度扩展技术的奠基工作，常拿它与 RoPE 对比，也用来指认某些模型采用的位置编码方式。

学习路径

读这篇之前，按顺序读书架上的 3 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径帮你建立 Transformer 注意力、不同位置表示方式以及长上下文建模的前置知识，再看 ALiBi 如何用线性偏置做长度外推。

  1. 1
    Attention Is All You Need
    Attention Is All You Need注意力就是你所需要的一切 · 2017

    ALiBi 修改的正是 Transformer 的位置表示与注意力计算。

    读读缩放点积注意力与正弦位置编码，理解位置信息原本如何进入模型。

  2. 2
    BERT
    BERT: Pre-training of Deep Bidirectional Transformers for Language UnderstandingBERT：用于语言理解的深度双向 Transformer 预训练 · 2018

    BERT 使用可学习的绝对位置嵌入，是长度外推受限的典型例子。

    读抓输入表示里的位置嵌入部分，注意其最大长度固定为 512。

  3. 3
    Transformer-XL
    Transformer-XL: Attentive Language Models Beyond a Fixed-Length ContextTransformer-XL：超越固定长度上下文的注意力语言模型 · 2019

    Transformer-XL 的相对位置编码和段级循环是解决长上下文的前一代方案，ALiBi 与之对比。

    读读相对位置编码的设计和评估时使用更长上下文的做法。

  4. 4
    Train Short, Test Long
    Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation短训长测：用线性偏置注意力实现输入长度外推 · 2021 · 就是这篇

    不加位置嵌入，而是按距离给注意力分数加线性惩罚，实现短训长测。

    读重点读 ALiBi 的偏置公式与各头的斜率设置，以及外推到更长序列的困惑度实验。
