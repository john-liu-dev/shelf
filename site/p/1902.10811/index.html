Do ImageNet Classifiers Generalize to ImageNet?

ImageNet 分类器能泛化到 ImageNet 吗？
Benjamin Recht, Rebecca Roelofs, Ludwig Schmidt, Vaishaal Shankar · 2019

为 CIFAR-10 和 ImageNet 新建测试集，检验模型是否过拟合旧测试集

CIFAR-10 和 ImageNet 已被密集研究近十年，重复使用同一测试集有过拟合的风险。作者严格遵循原始数据集构建流程，为二者新建测试集，检验当前分类模型对新数据的泛化程度。评估多种模型后发现准确率在 CIFAR-10 上下降 3% 到 15%，在 ImageNet 上下降 11% 到 14%，但原测试集上的准确率增益会转化为新测试集上更大的增益。结果表明准确率下降并非由适应性过拟合造成，而是模型无法泛化到比原测试集略“更难”的图像。

HN 为什么提它

HN 上的人用它说明 ImageNet 和 CIFAR-10 的结果对测试集有轻微过拟合，同时旧测试集上的排名和更高的准确率大体仍能转移到新数据上。

学习路径

读这篇之前，按顺序读书架上的 6 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先了解 ImageNet 基准和测试集复用的问题，再认识被检验的几类代表性卷积网络，才能看懂新测试集上的精度下降说明了什么。

    ImageNet Large Scale Visual Recognition Challenge
    ImageNet Large Scale Visual Recognition ChallengeImageNet 大规模视觉识别挑战 · 2014

    目标论文要重建 ImageNet 测试集，需要了解原数据集的构造与评测方式。

    读数据收集、标注流程和 top-1 与 top-5 指标。

  2. 2
    The Ladder
    The Ladder: A Reliable Leaderboard for Machine Learning Competitions2015

    它讨论多次复用测试集会带来的过拟合风险，正是目标论文的动机。

    读排行榜过拟合与阈值化的思路，抓住自适应复用的问题。

  3. 3
    Very Deep Convolutional Networks for Large-Scale Image Recognition
    Very Deep Convolutional Networks for Large-Scale Image Recognition面向大规模图像识别的极深卷积网络 · 2014

    VGG 是被评估的早期模型之一，代表朴素堆叠的深度网络。

    读架构特点即可，对照后来模型在新测试集上的表现。

  4. 4
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    ResNet 是被评估的核心模型家族，残差结构也是其后模型的基础。

    读残差块的设计，不必细读检测任务部分。

  5. 5
    Densely Connected Convolutional Networks
    Densely Connected Convolutional Networks密集连接卷积网络（DenseNet） · 2016

    DenseNet 是被评估的另一类架构，用来观察不同设计的泛化表现。

    读密集连接的设计，了解它与 ResNet 的差别。

  6. 6
    Learning Transferable Architectures for Scalable Image Recognition
    Learning Transferable Architectures for Scalable Image Recognition学习可迁移的架构以实现可扩展的图像识别（NASNet） · 2017

    NASNet 属于通过架构搜索得到的新模型，是被评估的高精度模型之一。

    读搜索出的单元如何堆叠，只需大意。

  7. 7
    Do ImageNet Classifiers Generalize to ImageNet?
    Do ImageNet Classifiers Generalize to ImageNet?ImageNet 分类器能泛化到 ImageNet 吗？ · 2019 · 就是这篇

    读新测试集的构造方法、精度下降的数据，以及对分布偏移与过拟合的讨论。
