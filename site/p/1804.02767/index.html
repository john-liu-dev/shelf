对 YOLO 做了一批小的设计改动，并训练了一个更大但仍然很快的新网络。在 320x320 输入下耗时 22 ms、28.2 mAP，精度与 SSD 相当但快三倍；按旧的 0.5 IOU 指标，在 Titan X 上 51 ms 达到 57.9 mAP@50，与 RetinaNet 的 57.5（198 ms）相近而快 3.8 倍。

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先看两阶段检测器和 YOLO 的前两代，再看残差主干和更强的单阶段对手，才能读懂 YOLOv3 做了哪些渐进式改进。

  1. 1
    Faster R-CNN
    Faster R-CNN: Towards Real-Time Object Detection with Region Proposal NetworksFaster R-CNN：用区域建议网络实现实时目标检测 · 2015

    它是 YOLO 系列对比的两阶段检测范式，其 anchor 思路也被后续 YOLO 采用。

    读区域建议网络与 anchor 框的概念。

  2. 2
    You Only Look Once
    You Only Look Once: Unified, Real-Time Object DetectionYou Only Look Once：统一的实时目标检测 · 2015

    YOLOv3 是第一版 YOLO 的延续，需要先理解把检测当作回归的基本框架。

    读网格划分、每格预测边界框与类别概率，以及损失函数。

  3. 3
    Deep Residual Learning for Image Recognition
    Deep Residual Learning for Image Recognition用于图像识别的深度残差学习 · 2015

    YOLOv3 的新主干网络 Darknet-53 使用了残差连接。

    读残差块的设计与恒等跳连的作用。

  4. 4
    YOLO9000
    YOLO9000: Better, Faster, StrongerYOLO9000：更好、更快、更强 · 2016

    YOLOv2 引入了 anchor 框、聚类选框和批归一化等改进，YOLOv3 直接建立在其上。

    读anchor 框与维度聚类、直接位置预测，以及多尺度训练。

  5. 5
    Focal Loss for Dense Object Detection
    Focal Loss for Dense Object Detection2017

    RetinaNet 与 focal loss 是 YOLOv3 在速度与精度对比中的主要对手。

    读类别不平衡问题与 focal loss 的形式，了解单阶段检测的难点。

  6. 6
    YOLOv3
    YOLOv3: An Incremental ImprovementYOLOv3：渐进式改进 · 2018 · 就是这篇

    在前面几代模型与对手的背景下，看 YOLOv3 的一系列小改进。

    读多尺度预测、新主干网络、边界框预测与类别预测的改动，以及对比表格。
