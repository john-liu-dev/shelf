论文表明 LLM 可以仅靠无标签数据集自我改进：用预训练 LLM 借助思维链（Chain-of-Thought）提示和自洽性，为无标签问题生成高置信度的带推理过程的答案，再把这些自生成的解答作为目标输出来微调同一个模型。在 5400 亿参数的 LLM 上，GSM8K 从 74.4% 提升到 82.1%，DROP 从 78.2% 到 83.0%，OpenBookQA 从 90.0% 到 94.4%，ANLI-A3 从 63.4% 到 67.9%，达到最先进水平且无需任何真实标签；消融实验表明在推理上微调对自我改进至关重要。

HN 为什么提它

HN 上的人把它作为 LLM 可以通过在自己的高置信度输出上训练来改进的例子，用来讨论模型自我改进是否可行。

方法难度 3 / 5约 40 分钟经得起时间
读之前最好知道

2自洽性（self-consistency）解码
3监督微调（fine-tuning）
4推理基准（GSM8K 等）
