提出 MusicGen，一个在多路压缩离散音乐表示（token）上运行的单一语言模型。它采用单阶段 Transformer 配合高效的 token 交错模式，无需像以往工作那样级联多个模型（分层或上采样）。可生成单声道和立体声的高质量音乐，并以文本描述或旋律特征为条件；自动评测和人工评测都表明它在标准文本到音乐基准上优于对比基线，消融实验说明了各组件的作用，代码和模型已开源。

HN 为什么提它

评论者用它说明当前的音乐生成器（包括 Suno 式架构）是像 LLM 一样在 EnCodec 音频 token 上做下一个 token 预测，而不是图像式的去噪。
