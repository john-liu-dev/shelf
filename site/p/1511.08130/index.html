构造智能机器是计算机科学中最大的未解难题之一。论文提出这类机器应具备的若干基本性质，尤其关注交流与学习，讨论了一个可逐步教会机器自然语言交流基础的简单环境，作为与人类用户进行更复杂交互的前提，并就机器为了从环境中有效学习应支持哪类算法提出了一些猜想。

学习路径

读这篇之前，按顺序读书架上的 5 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径铺垫词向量、序列模型与带记忆的网络，以及 bAbI 这类用于渐进教学的任务，再读路线图本身。

  1. 1
    Efficient Estimation of Word Representations in Vector Space
    Efficient Estimation of Word Representations in Vector Space向量空间中词表示的高效估计 · 2013

    作者同属词向量工作的一脉，路线图中的语言学习设想建立在分布式词表示之上。

    读CBOW 与 skip-gram 的目标函数，以及词向量能学出的类比规律。

  2. 2
    Sequence to Sequence Learning with Neural Networks
    Sequence to Sequence Learning with Neural Networks用神经网络进行序列到序列学习 · 2014

    代表用循环网络端到端做序列映射的做法，路线图讨论的算法能力正是这类模型的局限所在。

    读编码器-解码器 LSTM 的结构，以及它在长序列和需要显式算法的任务上的不足。

  3. 3
    Neural Turing Machines
    Neural Turing Machines神经图灵机 · 2014

    给网络配外部可微记忆，是路线图谈到的「机器应支持的算法」的一类实现尝试。

    读读写头的内容寻址与位置寻址，以及它能学会的简单算法任务（复制、排序）。

  4. 4
    Learning to Transduce with Unbounded Memory
    Learning to Transduce with Unbounded Memory学习使用无界记忆进行序列转换 · 2015

    用可微栈、队列扩展循环网络的记忆，与路线图所说的结构化记忆直接相关。

    读栈和队列的连续化（可微）定义，以及它在转换任务上相对普通 LSTM 的优势。

  5. 5
    Towards AI-Complete Question Answering
    Towards AI-Complete Question Answering: A Set of Prerequisite Toy Tasks迈向 AI 完备的问答：一组前置玩具任务 · 2015

    提出 bAbI 玩具任务，思路与路线图用简单环境渐进教学一致。

    读各类任务（单事实、多事实推理、计数等）为何被视作前置能力，以及它的评测方式。

  6. 6
    A Roadmap towards Machine Intelligence
    A Roadmap towards Machine Intelligence迈向机器智能的路线图 · 2015 · 就是这篇

    目标论文：提出智能机器应具备的性质，并设计渐进学习的语言环境。

    读对机器应具备的沟通与学习性质的论述，那个简单环境的设定，以及对算法的猜想。
