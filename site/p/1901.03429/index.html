论文研究 Transformer 和 Neural GPU 这两种基于注意力和卷积的代表性架构的计算能力，证明二者仅凭计算和访问内部稠密表示的能力就是图灵完备的，不需要外部存储器。研究还找出了获得这些完备性结果所需的最小元素集合。

HN 为什么提它

评论者用它反驳「Transformer 做不了通用计算」的说法，但也有人补充：证明依赖任意精度算术，实际有限精度的实现并不满足这一条件。

学习路径

读这篇之前，按顺序读书架上的 4 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

先看带外部记忆和栈的神经网络，再看 Transformer 与 Universal Transformer，就能理解为什么需要研究这些架构的计算能力，以及目标论文的图灵完备性证明。

  1. 1
    Neural Turing Machines
    Neural Turing Machines神经图灵机 · 2014

    神经图灵机是最早讨论神经网络与图灵机类比的工作，给出了计算能力问题的背景。

    读可微外部记忆与读写头的设计，以及它学会的简单算法任务。

  2. 2
    Inferring Algorithmic Patterns with Stack-Augmented Recurrent Nets
    Inferring Algorithmic Patterns with Stack-Augmented Recurrent Nets用栈增强的循环网络推断算法模式 · 2015

    给循环网络配上可微栈来学习算法模式，是扩展网络计算能力的同类尝试。

    读栈增强循环网络的结构，以及它能处理哪类形式语言。

  3. 3
    Attention Is All You Need
    Attention Is All You Need注意力就是你所需要的一切 · 2017

    目标论文要证明的对象之一就是 Transformer，需要先熟悉其结构。

    读自注意力、位置编码和编码器-解码器结构；证明里要用到注意力如何取值。

  4. 4
    Universal Transformers
    Universal Transformers通用 Transformer · 2018

    Universal Transformer 引入循环结构，与目标论文关于 Transformer 计算能力的讨论直接相关。

    读跨深度共享参数的循环式 Transformer，以及它与普通 Transformer 的区别。

  5. 5
    On the Turing Completeness of Modern Neural Network Architectures
    On the Turing Completeness of Modern Neural Network Architectures论现代神经网络架构的图灵完备性 · 2019 · 就是这篇

    目标论文：证明 Transformer 与 Neural GPU 在能够计算和访问内部稠密表示的前提下都是图灵完备的。

    读证明的构造思路：用注意力读取内存、用层的堆叠或循环模拟图灵机的步骤。
