研究把 Merkle-DAG 用作无冲突复制数据类型（CRDT）的传输与持久层，提出 Merkle-CRDT 一词并概述相关概念、性质、优点与局限。Merkle-DAG 可充当逻辑时钟，使收敛数据类型在消息层保证较弱、副本数量极大的系统里更易设计和实现，并可借助 DHT、PubSub 以及内容寻址带来的安全和去重性质。

HN 为什么提它

评论者把它当作无需先验知识的 CRDT 入门，也说若要自己实现，它能给出核心思想，并常用它说明 Merkle 时钟和 DAG 内嵌 CRDT 的出处。

学习路径

先了解 CRDT 的基本概念和两类变体，再看用于文档的 JSON CRDT，最后读 Merkle-DAG 如何作为 CRDT 的传输与持久层。

    Conflict-free Replicated Data Types (CRDTs)

    Delta State Replicated Data TypesDelta 状态复制数据类型 · 2016

    读delta 的定义与合并的做法，以及它与完整状态传输的对比。

  3. 3
    A Conflict-Free Replicated JSON Datatype
    A Conflict-Free Replicated JSON Datatype无冲突复制的 JSON 数据类型 · 2016

    它给出复杂数据结构（JSON）的 CRDT，说明 CRDT 在实际应用里的样子。

    读嵌套列表与映射的操作语义，以及并发操作如何合并。

  4. 4
    Merkle-CRDTs
