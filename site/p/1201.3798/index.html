No need for conspiracy: Self-organized cartel formation in a modified trust game

论文研究一个混合人群中的信任博弈：买家被迫与预定数量的、可动态选择的卖家交易，卖家则根据收益调整商品的性价比。动力学在策略更新率的某个值处发生转变，高于该值时出现自发的卡特尔组织，卖家的性价比趋于相近且低于最优。这种卡特尔并非来自明确合谋，而是个体收益最大化的自发结果；其动力学波动大、可预测性低，可作为某些商品价格居高且波动的一种定性解释。

HN 为什么提它

HN 上的人多次引用它来说明卡特尔可以在没有阴谋合谋的情况下自发形成，仅靠个体行为或策略更新率差异就够了；也有人批评其模型存在结构性问题。
