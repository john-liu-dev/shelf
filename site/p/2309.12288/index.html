The Reversal Curse: LLMs trained on "A is B" fail to learn "B is A"

逆转诅咒：在「A 是 B」上训练的 LLM 学不会「B 是 A」
Lukas Berglund, Meg Tong, Max Kaufmann, Mikita Balesni, Asa Cooper Stickland, Tomasz Korbak, Owain Evans · 2023

自回归大模型学了「A 是 B」，却不能自动推出「B 是 A」

揭示自回归 LLM 的一个泛化失败：模型在形如「A 是 B」的句子上训练后，不会自动泛化到反方向「B 是 A」，且正确答案的似然不比随机名字更高，这就是逆转诅咒。若「A 是 B」出现在上下文中，模型则能推出反向关系。作者用虚构陈述微调 GPT-3 和 Llama-1 验证，并发现该现象在不同模型规模和家族中稳健、数据增强也无法缓解；在真实名人问题上，GPT-4 回答「某人的母亲是谁」的正确率为 79%，反向问题仅 33%。

HN 为什么提它

HN 上的人用它来说明 LLM 在推理和泛化上的缺陷：训练时学到的事实反向提问就答不出来，似乎更像检索而非真正理解，并把它与「能力参差」的论点并列。
