Extracting books from production language models

用 BoN 越狱加迭代续写，从四个商用 LLM 中提取整本书

围绕 LLM 与版权的许多法律问题都归结为记忆：训练数据是否被编码进权重、能否从输出中被提取。作者用两阶段流程检验生产级 LLM 能否被提取受版权保护的书籍：先做探测（有时用 Best-of-N 越狱），再用迭代续写提示尝试提取整本书，并以基于最长公共子串块近似的 nv-recall 评分。在 Claude 3.7 Sonnet、GPT-4.1、Gemini 2.5 Pro 和 Grok 3 上，Gemini 和 Grok 无需越狱即可提取（《哈利·波特与魔法石》nv-recall 分别为 76.8% 和 70.3%），越狱后的 Claude 3.7 Sonnet 在某些情况下近乎逐字输出整本书（nv-recall 95.8%），GPT-4.1 需要多得多的 BoN 尝试并最终拒绝继续（nv-recall 4.0%）。结论是即使有安全防护，提取受版权保护的训练数据仍是生产级 LLM 的风险。

HN 为什么提它

评论者在争论 LLM 是否记忆并复现训练数据时引用它，作为生产级模型能近乎逐字复现整本书（如 Claude 3.7 Sonnet 复现哈利·波特第一部 95.8%）的证据，也有人指出这对多数文本并不成立。
