模糊测试概念简单、部署门槛低，且在发现真实软件漏洞方面有大量经验证据，因而一直非常流行，但近年大量工作也让人难以对其形成全面一致的认识。论文提出统一的通用模糊测试模型和对现有文献的分类体系，并沿着该模型逐阶段系统考察设计决策，综述使现代模糊器有效的艺术、科学与工程方面的相关文献和创新。

HN 为什么提它

HN 评论者把它作为想广泛了解模糊测试技术时推荐的综述。

综述难度 3 / 5约 150 分钟经得起时间

3软件测试基础
4操作系统与二进制基础

学习路径

读这篇之前，按顺序读书架上的 4 篇 · 参考文献来自 OpenAlex，顺序和要点由 Claude Code 排出

这条路径先从与模糊测试紧邻的安全检测与实践入手，再看一个代表性的现代 fuzzer 和机器学习方法，最后读作者对评估方法的讨论，以便理解综述里的统一模型与设计决策。

  1. 1
    SoK
    SoK: Sanitizing for Security2018

    sanitizer 用来在测试时暴露内存错误，是模糊测试判定漏洞（oracle）的重要一环。

    读各类 sanitizer 能检测的错误类型及其开销；与 fuzzing 配合的方式。

  2. 2
    Angora
    Angora: Efficient Fuzzing by Principled SearchAngora：基于原则性搜索的高效模糊测试 · 2018

    Angora 是现代 fuzzer 的代表，展示不用符号执行也能求解路径约束。

    读污点追踪、梯度下降式搜索与路径约束的处理；对照综述里的输入调度与变异。

  3. 3
    Learn&Fuzz
    Learn&Fuzz: Machine Learning for Input Fuzzing2017

    用机器学习学习输入语法来生成测试，对应综述里生成式输入的思路。

    读如何用神经网络学习输入格式并生成测试输入；只需抓住总体方法。

  4. 4
    Evaluating Fuzz Testing
    Evaluating Fuzz Testing2018

    讨论如何科学地评估 fuzzing，与综述中对评估方法的关注直接相关。

    读对既有 fuzzer 论文评估方式的检查，以及推荐的实验设置。

  5. 5
    The Art, Science, and Engineering of Fuzzing
    The Art, Science, and Engineering of Fuzzing: A Survey模糊测试的艺术、科学与工程：综述 · 2018 · 就是这篇

    给出统一的模糊测试模型，并按设计决策梳理文献。

    读先抓统一模型各环节（调度、变异、评估等），再按兴趣选读各设计决策的小节。
