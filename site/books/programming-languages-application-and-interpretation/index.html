Shriram Krishnamurthi 写的程序语言教材，用 Racket 实现一个个小解释器，来讲解函数、闭包、惰性求值、continuation 和类型推导等语言特性。写法是先动手实现、再讨论背后的理论，配有练习，作者还公开了视频课程。和 SICP 相比更聚焦语言实现与语义，不讲词法和语法分析，适合作为 SICP 之后的进阶读物。

HN 为什么推荐它

HN 上的人把它当作自学语言实现和类型系统的首选免费教材，常说它是 SICP 之后很好的衔接，类型推导的章节尤其被点名；有人提到它不涉及 parsing。

难度 3 / 5约 50 小时开放许可
适合谁

想自己实现编程语言、学习语言设计的程序员

读之前最好知道
1函数式编程基础
2递归（recursion）
3Scheme 或 Racket 基础

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先熟悉 Racket，再从最小的解释器那几章开始读
  2. 2每章的练习都动手写一遍，别只看代码
  3. 3对照作者的视频课程一起看，理解更快
  4. 4类型相关章节可在读完解释器部分后再读
