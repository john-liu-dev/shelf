这是一本由多位作者分章撰写的文集，每章用不超过 500 行代码实现一个真实可运行的程序，并讲解其中的设计思路和取舍。内容涉及多种类型的软件，不少章节用 Python 实现，包括 Guido van Rossum 写的基于 asyncio 的网络爬虫。和只讲架构概念的书不同，这本书让读者直接读完整的小型代码库，适合当作读源码的练习。

HN 为什么推荐它

HN 上的人把它当作读真实代码的入门材料推荐：项目小、不吓人，每章还配有分析，既能学 Python 也能看到不同类型软件的核心实现；也常拿 Guido 的 asyncio 爬虫章节举例。

难度 3 / 5约 30 小时开放许可
适合谁

想通过读小型真实代码学设计的中级开发者

读之前最好知道
1Python 基础
2基本数据结构与算法

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先看目录，挑自己熟悉或感兴趣的一章读，不必按顺序
  2. 2读完设计讲解后，把代码下载下来运行并改一改
  3. 3Guido 的爬虫一章适合想学 asyncio 的人先读
  4. 4可与 The Architecture of Open Source Applications 配合着读
