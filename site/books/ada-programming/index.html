Ada Programming Wikibook 由 Wikibooks 社区志愿者共同编写，是免费的 Ada 语言综合教程，内容涉及类型系统、范围类型、泛型、异常、并发等语言特性。它是维基形式，既能当入门教程顺序读，也能当参考手册按主题查。和 AdaCore 的 learn.adacore.com 相比，它更像一份持续编辑的参考资料，各页质量和完整度不一，部分页面还不完整。

HN 为什么推荐它

HN 上讨论 Ada 的人常把它作为免费的入门资源推荐，有人配合二手教科书使用，也有人把它与 learn.adacore.com 并列。有评论指出它比较全面但仍有不少缺页；它也常被引用来说明 Ada 的范围类型和子类型。

难度 2 / 5约 30 小时开放许可
适合谁

想学 Ada 的程序员，尤其对安全关键软件感兴趣的人

读之前最好知道
1一门编程语言基础
2静态类型概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先通读基础语法和类型部分，再按需查阅其他章节
  2. 2配合 learn.adacore.com 的交互式教程一起读
  3. 3遇到缺页或过时内容时，查 Ada 参考手册补充
  4. 4亲手装 GNAT 编译器，把例子都敲一遍
