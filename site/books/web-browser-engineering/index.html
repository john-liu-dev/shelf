Pavel Panchekha 和 Chris Harrelson 合写的教材，带读者用 Python 一步步实现一个图形界面的小型浏览器，涵盖网络请求、HTML 解析、排版渲染和脚本执行等环节。以边讲边实现的方式推进，每章都在前一章的代码上加功能。能让人看清浏览器各部分如何配合，也是理解 Web 平台的一条动手路线。

HN 为什么推荐它

HN 上的人推荐它，主要因为能亲手做出一个真正能用的浏览器，学得很有趣；有人把它看作 Web 方向的 SICP 式教材，也有人读完自己写了玩具浏览器。

难度 3 / 5约 40 小时
适合谁

想弄懂浏览器如何工作的开发者

读之前最好知道
1Python 编程
2HTML 与 CSS 基础
3HTTP 基本概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从第一章开始，按顺序跟着写代码，不要只看不做
  2. 2每章先让程序跑起来，再回头读原理
  3. 3遇到不熟的 Web 概念，配合 MDN 之类的文档查阅
  4. 4做完主线后，可自己加功能练手
