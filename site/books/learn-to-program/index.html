Chris Pine 用 Ruby 讲编程入门，从最基本的数字、字符串和变量，讲到流程控制、方法和对象，语气轻松，节奏舒缓。教程里有不少可以自己动手解决的小任务，几小时就能跟着走完一遍。它后来被扩展成 Pragmatic Programmers 出版的书，网上这一版是免费的原始教程。

HN 为什么推荐它

HN 上的人常把它推荐给零基础的朋友或孩子，认为它是学编程和 Ruby 的温和起点，易读、有动手任务，有人说是最好的编程教程之一。

难度 1 / 5约 8 小时
适合谁

零基础、想用 Ruby 入门编程的人

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从头顺序读，每章都亲手敲例子
  2. 2多做每章的小练习，别只看不写
  3. 3读完后转向 Ruby 或 Rails 的更深入教材
  4. 4有人陪着读效果更好，两个小时就能带完
