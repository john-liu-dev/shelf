Composing Programs 是 UC Berkeley CS 61A 课程的讲义，以 SICP 为蓝本，改用 Python 讲抽象、高阶函数、递归、数据结构、面向对象和解释器等主题。John DeNero 的写法比 SICP 更简洁，书中嵌入 Python Tutor，可以逐步查看代码的执行过程。每章配有课程练习，适合边读边做。和 SICP 相比，它换成更主流的语言，门槛更低，但函数式风格和语言实现的内容不如 SICP 深。

HN 为什么推荐它

HN 上的人常把它当作“用 Python 学 SICP”的替代品推荐给想学 Python 或想入门计算机科学的人，也提到嵌入式代码可视化很有教学价值；批评主要是书没有讨论递归深度限制、栈溢出等 Python 实际会遇到的问题。

难度 2 / 5约 40 小时开放许可
适合谁

想系统学编程思想的 Python 初学者，或想读 SICP 却嫌 Scheme 陌生的人

读之前最好知道
1基本编程概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从第一章开始，别跳过函数和高阶函数的部分
  2. 2用书里的 Python Tutor 可视化逐步跟踪递归和环境模型
  3. 3做每章配套的练习，最好再对照 CS 61A 的课程作业
  4. 4读完想深入语言实现，再去读 SICP 对照
