Steven Bird、Ewan Klein、Edward Loper 写的 NLTK 配套教材，用 Python 讲自然语言处理的基础：文本处理、词性标注、文本分类、信息抽取和句法分析等。全书以大量可运行的代码示例带着读者动手，每章有练习，数学负担很轻。和偏统计、偏深度学习的现代 NLP 教材相比，它更偏计算语言学和入门实践，内容有些年头，但概念框架仍然清晰。

HN 为什么推荐它

十几年来 HN 上的人都把它当作 NLP 的第一站来推荐：免费在线、实践为主、数学少、概念讲得清楚，常用来回答分词、词性标注、实体抽取、文本分类这类问题；2023 年有人提到它可能有点过时。

难度 2 / 5约 30 小时开放许可
适合谁

想动手入门 NLP 的 Python 程序员

读之前最好知道

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先装好 NLTK，跟着前几章在笔记本里把代码都跑一遍
  2. 2想做机器学习相关任务，可直接跳到文本分类那一章
  3. 3做每章的练习，比只看示例收获大得多
  4. 4读完再配一本现代 NLP 教材，补上神经网络方法
