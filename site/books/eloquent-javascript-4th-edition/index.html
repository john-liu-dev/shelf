Marijn Haverbeke 从语言基础讲到函数、对象、异步编程，再到浏览器 DOM 和 Node.js，并有几个完整的小项目。网页版自带可在浏览器里直接运行和修改的代码，每章有练习。和只讲语法的参考书相比，它更重视编程思维和函数式写法，文风幽默。这里是第四版。

HN 为什么推荐它

HN 上的人长期把它推荐给想学 JavaScript 的人，理由是内容全面、免费，网页上可以直接运行代码，对各种水平的读者都有收获，也有人提到它有的部分对小孩偏干。

难度 2 / 5约 40 小时开放许可
适合谁

想系统学 JavaScript 的初学者和转行者

读之前最好知道
1基本的计算机使用能力

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1用网页版阅读，边读边在内嵌编辑器里改代码
  2. 2每章末的练习都做，卡住了再看提示
  3. 3函数式编程的章节想读透，可以多花时间
  4. 4学完基础后做书里的项目章节，再去读浏览器相关部分
