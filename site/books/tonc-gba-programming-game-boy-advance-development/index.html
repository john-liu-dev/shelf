Tonc 是 Jasper Vijn 写的 Game Boy Advance 编程教程，从开发环境、寄存器和显示模式讲起，逐步覆盖背景、精灵、中断、DMA、定时器等硬件功能，全部用 C 语言配合示例代码演示。另有一篇很短的 ARM 汇编速览，不少人单独拿来学 ARM 指令集。和只给硬件手册的资料不同，它把硬件细节讲成可以动手跑的教程，是 GBA 自制游戏圈公认的起点。

HN 为什么推荐它

HN 上有人把它称作做 GBA 游戏时大家都在用的资源，还有人当作学 ARM 汇编的好教程反复推荐；也常被当作 GBA 编程的参考资料引用。

难度 3 / 5约 40 小时
适合谁

想动手给 GBA 写游戏，或想学 ARM 汇编的人

读之前最好知道
1C 语言指针
2二进制与位运算（bitwise）

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先搭好开发环境，跑通前几章的第一个示例再往下读
  2. 2边读边在模拟器里运行示例，把代码改一改看效果
  3. 3只想学 ARM 汇编的话，直接读那篇汇编速览即可
  4. 4遇到具体硬件功能（精灵、DMA 等）时再回头查对应章节
