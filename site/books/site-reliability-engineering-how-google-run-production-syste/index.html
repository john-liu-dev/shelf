Betsy Beyer 等人编写，由 Google 的工程师分章撰写，讲述 Google 如何运维大规模生产系统：SLO 与错误预算、监控、事故响应、复盘、减少 toil、负载均衡与过载处理等。每章相对独立，可以按主题挑着读。和一般的运维手册相比，它把运维当作软件工程问题，更侧重原则和思路，而不是具体工具的操作步骤。

HN 为什么推荐它

HN 上的人在讨论监控、值班、事故和可靠性时常引用它，SLO、错误预算、无责复盘、toil 等章节被反复点名，也有人说它是理解 SRE 的好起点。

难度 3 / 5约 30 小时开放许可
适合谁

做后端、运维或值班的工程师及技术管理者

读之前最好知道
1Linux 运维基础
2分布式系统基础概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读开头几章，弄清 SRE 和传统运维的区别
  2. 2SLO、错误预算、监控、复盘等章节优先读
  3. 3每章相对独立，可按当前工作遇到的问题挑着读
  4. 4负载均衡和过载等偏技术的章节可后读
