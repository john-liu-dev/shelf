Kenneth Reitz 等人维护的 Python 实践指南，在线免费，也有出版成书的版本。内容覆盖安装与环境配置、虚拟环境、项目结构、代码风格、测试，以及各应用领域的常用库和工具。和语法教程不同，它不教语言本身，而是帮已经会写 Python 的人了解社区的做法和常见陷阱，各章基本可以独立阅读。

HN 为什么推荐它

HN 上的人把它当作 Python 最佳实践和工具链的导览：适合在入门后了解虚拟环境、测试、项目结构等，也有人用它讲 Python 的常见陷阱；整体是正面推荐。

难度 2 / 5约 15 小时开放许可
适合谁

已会基本语法、想学工程实践的 Python 开发者

读之前最好知道
1Python 基础语法

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1各章可以独立读，按自己遇到的问题挑着看
  2. 2先看环境搭建、项目结构和测试相关的部分
  3. 3读代码风格和常见陷阱章节时对照自己写过的代码
  4. 4具体工具的版本变化快，以官方文档为准
