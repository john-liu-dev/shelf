Steve Losh 写的 Vimscript 入门教程，按短章节逐步讲解映射、选项、变量、函数、自动命令，最后带读者写一个完整的插件。风格沿用“笨办法”系列：每章都有要敲进编辑器的例子。内容基于传统 Vimscript，书中也讲了不少 Vim 本身的运作逻辑。和直接翻 Vim 帮助文档相比，它的顺序更适合循序渐进地学。

HN 为什么推荐它

HN 上的人推荐它，是因为写 Vim 插件时它几乎是最好的入门资料；也有人说读完后对 Vim 的语义理解更深。2026 年有评论提到它有些过时，但对理解传统 Vimscript 仍有帮助。

难度 2 / 5约 12 小时
适合谁

已经会用 Vim、想自定义配置或写插件的人

读之前最好知道
1Vim 基本操作
2任意一门编程语言

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先会用 Vim 的基本操作，再从映射和选项几章开始读
  2. 2每章的例子都亲手敲进 Vim 里试一遍
  3. 3读完前面基础后，跟着书里的插件项目走一遍
  4. 4只想用 Vim 不写插件，也可以挑讲映射、operator 的章节读
