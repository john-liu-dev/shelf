Pro Git 由 Scott Chacon 和 Ben Straub 撰写，是 Git 官网上的免费书。它先讲基本操作、分支和远程协作，再讲各种工作流和工具，并用附录解释 Git 内部如何存储数据。和命令速查类文档相比，它既教怎么用，也讲为什么这样设计，读完能真正理解 Git 的模型。

HN 为什么推荐它

HN 上的人遇到有人问怎么学 Git，常会推荐它，理由是讲得透彻、免费，能解释 Git 究竟如何工作；不少人说读完内部原理部分之后，Git 才真正想通了。

难度 2 / 5约 15 小时开放许可
适合谁

用过 Git 但没弄懂原理的开发者，以及新手

读之前最好知道
1命令行（command line）基本操作

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读基础和分支章节，边读边在终端里实际操作
  2. 2想弄懂原理，再读讲内部机制的章节和附录
  3. 3平时遇到具体问题，把它当作查阅手册
  4. 4和 man 手册配合着读，查命令细节
