这本书由 Yesod 框架作者 Michael Snoyman 撰写，介绍如何用 Haskell 和 Yesod 构建 Web 应用，涉及路由、模板（Hamlet 等）、Persistent 数据库访问、表单、认证和 REST 等内容。重点在于让类型系统在 Web 开发里发挥作用，在编译期保证更多正确性。它既是教程也是框架文档，随 Yesod 版本更新，也有 O'Reilly 的印刷版。

HN 为什么推荐它

HN 上的人把它当作 Yesod 和 Haskell Web 开发的权威资料推荐，有人称文档对 Yesod 1.4 仍然够新，适合已熟悉 Haskell 和 Web 开发的人入门；也有评论说它有时落后于框架的最新版本。

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读快速上手部分，把示例应用跑起来
  2. 2接着看路由、模板和 Persistent 数据库部分
  3. 3对 TemplateHaskell 和 QuasiQuotes 不熟的话先补一下
  4. 4留意书与你所用 Yesod 版本的差异，必要时查最新文档
