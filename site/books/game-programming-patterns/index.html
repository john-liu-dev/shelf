Robert Nystrom 写的设计模式书，把常见模式放到游戏开发的背景下讲，涵盖命令、观察者、状态、游戏循环、组件等内容，示例用 C++。文字清楚简洁，还带有作者自己的口吻。和经典的《设计模式》相比，它更现代，也更偏重在游戏里会遇到的实际问题，其中许多章节对非游戏开发者同样有用。

HN 为什么推荐它

HN 上的人推荐它，是因为写得清楚、有趣，而且内容超出游戏范围，适合想学软件设计与模式的人；常被当作《设计模式》的现代补充，也被引用来解释组合优于继承。

难度 3 / 5约 15 小时
适合谁

做游戏或想提升代码设计的程序员

读之前最好知道
1面向对象编程
2C++ 基础语法

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读开头对设计模式的介绍，再挑自己感兴趣的模式章节读
  2. 2游戏循环、组件、状态这几章最值得先读
  3. 3每章先想一下自己项目里是否遇到过这个问题，再看书里的解法
  4. 4可以和自己的小游戏项目配合着读
