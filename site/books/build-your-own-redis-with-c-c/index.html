怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1准备好 Linux 或 macOS 环境，每章先自己写，再对照书里的代码
  2. 2网页版解释较少，遇到不懂的概念先查 socket 和 epoll 资料
  3. 3同一作者另有用 Go 写数据库的书，可以做完这本再接着读
  4. 4想看更详细的讲解，可以考虑看付费的电子书或纸质版
