Mendel Cooper 编写、收录在 TLDP 的 Bash 脚本长篇指南，既能当教程顺序读，也能当参考手册查。内容涵盖变量、引用、测试、循环、函数、进程替换、here document 等语法，并附有大量完整的示例脚本。它的特点是细节全、例子多，但条目偏多、编排不算紧凑，更适合查阅而不是一口气读完。

HN 为什么推荐它

HN 上的人常把它当作学习和查阅 Bash 的现成资源，用来解释进程替换、退出码、算术展开等具体语法；有人指出示例脚本没有按难度排序，也有人觉得 TLDP 的其他 HOWTO 更实用易读。

难度 2 / 5约 25 小时开放许可
适合谁

要写或维护 Shell 脚本的开发者与运维

读之前最好知道
1Linux 命令行基础
2基本编程概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先学完基础，再带着具体问题来查对应章节
  2. 2边读边在终端里运行示例，改改参数看结果
  3. 3重点看引用、参数展开和进程替换这几类易错处
  4. 4可以和 man bash 配合，遇到分歧以手册为准
