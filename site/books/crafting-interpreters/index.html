Robert Nystrom 带读者从头写出同一门语言 Lox 的两个解释器：先用 Java 写树遍历版，再用 C 写字节码虚拟机。每一章都有完整代码和讲解，包括扫描、解析、变量、闭包、类和垃圾回收等。和偏理论的编译原理教材相比，它更动手，写法也轻松。网页版可免费阅读。

HN 为什么推荐它

HN 上的人把它当作入门语言实现的首选，称赞写得清楚、有趣，适合没有编译原理背景的人，也常和 Writing An Interpreter in Go 一起推荐。早年有人读的是未完成版，仍然给了很高评价。

难度 3 / 5约 50 小时开放许可
适合谁

想亲手写一门语言的程序员

读之前最好知道
1Java 或 C 语言
2递归（recursion）
3基本数据结构，例如哈希表（hash table）

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从头开始，跟着每一章自己敲出代码，不要只复制
  2. 2先完成前半部分的树遍历解释器，再做字节码虚拟机
  3. 3每章末的挑战题值得做，能加深对语言特性的理解
  4. 4想看理论补充，可再配合一本编译原理教材
