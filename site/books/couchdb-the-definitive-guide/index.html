O'Reilly 出版的 CouchDB 官方风格指南，作者免费放出在线版，采用 CC-BY-3.0 许可。书从 CouchDB 的 RESTful HTTP 接口讲起，用 curl 一步步演示文档、视图、map/reduce、验证函数、变更通知和复制等核心概念，并涉及内部的 B-tree 存储设计。和泛泛介绍 NoSQL 的书相比，它紧扣一个具体系统，动手例子多。出版时间较早，示例里的版本号已经偏旧。

HN 为什么推荐它

HN 上的人常把它当作 CouchDB 的标准参考：解释 changes API、过滤函数、验证函数、append-only B-tree 和复制时都会引它，也有人称它是入门 CouchDB 和 NoSQL 的好书；批评只有一条，在线版里示例的版本号太旧。

难度 3 / 5约 15 小时开放许可
适合谁

想了解文档型数据库和 CouchDB 的开发者

2JavaScript

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读开头的介绍和上手部分，用 curl 把文档的增删改查跑一遍
  2. 2接着读设计文档、视图和 map/reduce，这是 CouchDB 与其他数据库最不同的地方
  3. 3复制、变更通知和验证函数按需读，做离线同步类应用时最有用
  4. 4示例版本较旧，对照当前官方文档，遇到命令对不上时以官方文档为准
