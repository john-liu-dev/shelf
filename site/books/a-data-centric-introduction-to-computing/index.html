这本教材来自布朗大学的入门课程，围绕数据的结构来教编程：先用专为教学设计的 Pyret 语言，再过渡到 Python，并配有练习。内容强调从数据的形状出发设计程序，同时涉及基础的计算机科学概念。和 How to Design Programs 同源，但更偏数据处理，适合没有任何基础的读者。

HN 为什么推荐它

HN 上的人常把它与 How to Design Programs 一起推荐给零基础的人，称其讲解清楚、有教育研究支撑，也提到新版加了 Python 代码帮助学生过渡。

难度 1 / 5约 60 小时开放许可
适合谁

零基础想系统学编程思维的自学者

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从头顺序读，前半部分先用 Pyret 打好基础
  2. 2每章的练习都动手做，不要只看
  3. 3读到 Python 部分时，把前面的程序用 Python 重写一遍
  4. 4想深入程序设计方法，再读 How to Design Programs
