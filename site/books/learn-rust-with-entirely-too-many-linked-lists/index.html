Alexis Beingessner 写的 Rust 教程，一步步实现各种链表，从最简单的栈到更复杂的变体，过程中讲清 Box、引用、生命周期、借用检查器，以及 unsafe。写法幽默，重点是展示为什么链表在 Rust 里是个难题以及怎么解决。它和官方的 The Rust Book 互补：后者讲有哪些特性，这本讲实战里怎么用。

HN 为什么推荐它

HN 上的人几乎都把它推荐为理解借用检查器和 Rust 引用的必读材料，也常拿它回答“为什么在 Rust 里实现链表很难”；称它是循环、动态数据结构写法的权威参考。

难度 3 / 5约 15 小时开放许可
适合谁

学过 Rust 基础、想吃透所有权的人

读之前最好知道
1Rust 基础语法
2指针与引用概念
3链表（linked list）

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读完官方 The Rust Book 的基础部分再来
  2. 2每个链表版本自己敲一遍，并故意制造编译错误来理解提示
  3. 3先读前面几个安全版本，unsafe 部分等熟悉后再看
  4. 4遇到所有权困惑时回来重读相关章节
