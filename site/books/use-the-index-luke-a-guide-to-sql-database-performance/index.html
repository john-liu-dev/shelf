Markus Winand 写的在线教程，从开发者角度讲数据库索引如何存储、查询如何用到索引，以及where 条件、排序、分页、连接等写法对性能的影响。内容不绑定某一种数据库，同时标出各家数据库的差异。作者另有同主题的纸质书，这个网站是免费在线版。和泛泛的 SQL 入门不同，它只盯着性能这一个主题讲透。

HN 为什么推荐它

HN 上的人认为它是讲数据库索引最好的资源之一，说开发者几乎必读；常被引用来解释聚簇索引，以及用 keyset 分页代替 OFFSET 的做法。

难度 2 / 5约 12 小时
适合谁

写 SQL、关心查询性能的后端开发者

读之前最好知道
1基本 SQL 查询
2关系数据库的基本概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读索引的内部结构和 where 子句那几章，这是全书基础
  2. 2边读边在自己用的数据库上查看执行计划，验证例子
  3. 3分页、排序等专题可以遇到问题时单独翻阅
  4. 4和自己数据库的官方文档对照，注意各家的差异
