Michael Nielsen 以识别手写数字为主线，从感知机和 sigmoid 神经元讲到反向传播、改进训练的各种技巧，再到深度网络和卷积网络。书里有清楚的数学推导，也有可在本机运行的 Python 代码，还配有可交互的可视化解释。和只教调用框架的教程不同，它着重让读者弄懂神经网络为什么能工作。

HN 为什么推荐它

HN 上的人反复称它是最好的神经网络入门读物之一，尤其称赞第二章对反向传播的讲解既严谨又好懂，还附可运行代码，常出现在入门资源清单里。

难度 3 / 5约 25 小时开放许可

想弄懂神经网络原理的初学者

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错

  4. 4有余力就做书里的练习和问题
