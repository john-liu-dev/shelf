Laurens Van Houtven（lvh）写的免费密码学入门书，从基本概念讲起，涉及对称与非对称加密、哈希、密钥派生函数（KDF）、认证加密以及 PGP 等主题。写法面向非密码学专业的程序员，强调理解各种构造怎么用、会怎么被攻破。HN 上有评论说作者本人是真正的密码学家。读完可以建立对密码学的基本直觉，再进入更系统的课程。

HN 为什么推荐它

HN 上的人把它当作学密码学的起点，称赞它易懂、从头讲清楚公钥加密和 PGP 等；常与 Dan Boneh 的密码学课程并列推荐，用来补基础。

难度 2 / 5约 15 小时
适合谁

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从头顺序读，前面的概念后面会反复用到
  2. 2公钥加密和 PGP 部分可单独拿来读
  3. 3读完后接 Dan Boneh 的课程，补上数学和证明
  4. 4用 Python 时，实际写代码请用成熟的加密库
