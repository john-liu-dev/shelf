Daniel Shiffman 用 Processing（后来也有 p5.js 版本）写成的创意编程书，从向量、力和运动讲起，逐步到粒子系统、群体行为、元胞自动机、分形、遗传算法和神经网络。每章配有可运行的示例代码，风格轻松、重直觉。和一般的图形学或算法书相比，更偏向生成艺术和对自然现象的模拟。

HN 为什么推荐它

HN 上的人把它当作创意编程和生成艺术的首选入门，称赞它用物理和数学让代码更“自然”，示例清楚，还免费可读；也有人称它是很好的编程入门书。

难度 2 / 5约 50 小时开放许可
适合谁

想用代码做模拟与生成艺术的初学者

读之前最好知道
1基本编程概念
2中学物理与几何

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从向量和力的章节开始，边读边在 Processing 或 p5.js 里跑代码
  2. 2每章改改参数、自己做个小变体
  3. 3对群体行为、元胞自动机感兴趣的可先跳到相应章节
  4. 4神经网络部分作为入门了解即可
