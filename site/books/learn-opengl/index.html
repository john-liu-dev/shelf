Joey de Vries 的在线教程，用 C++ 和 GLFW 从创建窗口讲起，一步步到基于着色器的现代 OpenGL，包括摄像机、光照、模型加载以及阴影映射、延迟渲染和 PBR 等高级主题。每章配有图示和完整源码，循序渐进。它是官方免费在线阅读的网站，没有开放许可。与偏数学理论的图形学教材相比，更偏实践，适合边写边学。

HN 为什么推荐它

HN 上的人把它当作学图形编程最常推荐的资源，说它从基础讲起、解释清楚，PBR 部分也常被引用，学完后能把知识迁移到其他图形 API。

难度 3 / 5约 40 小时
适合谁

想入门图形编程、会写 C++ 的人

读之前最好知道
1C++ 基础
2线性代数（向量与矩阵）

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从入门部分的窗口、着色器和纹理开始，按顺序读
  2. 2每章都自己敲代码跑通，不要只复制
  3. 3读完光照部分后再看模型加载和高级主题
  4. 4想了解背后数学时配合图形学理论书看
