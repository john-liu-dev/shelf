Rust 官方项目写的进阶文档，讲 unsafe Rust 的工作方式：什么是安全、什么需要自己保证，以及数据在内存里的表示、子类型和变型（variance）、Send 与 Sync 等。其中有一部分带读者从头实现 Vec 等数据结构，是不错的实战材料。和 The Rust Programming Language 不同，它假定读者已会写 Rust，专讲底层细节。

HN 为什么推荐它

HN 上的人把它当作学习 unsafe Rust 和理解 Rust 安全保证的首选资料，常被引用来解释数据竞争、变型、PhantomData、FFI 和并发；也有人批评它更新慢、还有一些未写完的 TODO。

难度 4 / 5约 20 小时开放许可
适合谁

已会写 Rust、想弄懂 unsafe 的开发者

读之前最好知道
1Rust 基础与所有权（ownership）
2C 语言指针
3内存布局基础

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先学完一本 Rust 入门书，再来读这份文档
  2. 2从安全与不安全的边界和内存表示读起，建立整体概念
  3. 3跟着实现 Vec 的部分动手写一遍，比只看更有效
  4. 4变型、PhantomData 这类概念当作查阅用的参考，反复回看
