Brian Hall（Beej）写的 C 语言教程，用口语化、带幽默感的文字讲解语法、指针、结构体等核心内容。文风轻松，读起来不枯燥，更适合已经会一门语言、想快速掌握 C 的读者。提供 HTML、PDF 等多种格式，可在手机上阅读。和传统 C 教材相比更短小随意，但严谨性不及经典教材，作者自己也把它标为尚在完善的文档。

HN 为什么推荐它

HN 上的人常把它推荐给想入门 C 的人，称赞文风有趣、容易读下去，也有人说它是自己学 C 的起点；也有评论批评部分写法走捷径、不够严谨。

难度 2 / 5约 25 小时开放许可
适合谁

有编程基础、想快速学 C 的人

读之前最好知道
1任意一门编程语言基础
2命令行与编译器的基本使用

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1有其他语言基础的话，从头顺着读，边读边在本机敲例子
  2. 2指针和结构体部分多花时间，自己写小程序验证
  3. 3读到不放心的地方，对照一本严谨的 C 教材或标准文档
  4. 4想做网络编程，可接着读作者的网络编程指南
