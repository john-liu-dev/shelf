Jack W. Crenshaw 的系列教程，从最小的表达式解析器出发，每一章只加一点功能，逐步长成能生成汇编的完整小编译器。全程采用递归下降（recursive descent）和直接生成代码的做法，不依赖 lex、yacc 之类的自动工具，行文口语化、几乎没有形式化理论。代码用 Pascal 写成，年代较久，但思路可以搬到任何语言。和龙书这类系统教材相比，它更像边做边讲的实操手记，适合先建立信心再去读理论。

HN 为什么推荐它

HN 上的人把它当作编译器入门的首选推荐：认为它让编译器不再吓人，一步步跟着做就行，用什么语言实现都可以；也有人提醒它年代久、用 Pascal，但仍然有启发。

难度 2 / 5约 15 小时
适合谁

想亲手写第一个编译器的自学者

读之前最好知道
1基本编程能力
2递归（recursion）
3汇编语言基础概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从头按章节顺序读，跟着敲代码，不要跳章
  2. 2用你熟悉的语言重写示例，不必拘泥于 Pascal
  3. 3读完再配合一本讲词法、语法分析和优化的教材补理论
  4. 4把它当第一本编译器读物，别指望覆盖类型系统和现代优化
