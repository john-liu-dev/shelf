Kyle Simpson 写的一套分册系列，不教入门语法，而是深挖 JavaScript 的核心机制，如作用域与闭包、this 与对象原型、类型与语法、异步与性能等。行文带有明确的观点，鼓励读者弄清语言真实的工作方式而不是靠经验猜。和面向初学者的教程相比，它更适合已经写过 JS、想补足底层理解的人。免费放在 GitHub 上。

HN 为什么推荐它

HN 上的人认为它能帮人从根上理解 JavaScript，尤其是作用域、闭包、this、Promise 和异步；比起追逐框架，这类深层知识更耐用。也有人称 Scope and Closures 那一册让自己真正开窍。

难度 3 / 5约 30 小时开放许可
适合谁

写过 JavaScript、想弄懂语言机制的开发者

读之前最好知道
1JavaScript 基础语法
2基本的 HTML 与浏览器知识

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读作用域与闭包那一册，再读 this 与对象原型
  2. 2有一定 JS 经验再读，纯新手先看入门教程
  3. 3异步部分可以与 Promise 的实际用法对照着读
  4. 4遇到不同意的观点就写代码验证，不必全盘接受
