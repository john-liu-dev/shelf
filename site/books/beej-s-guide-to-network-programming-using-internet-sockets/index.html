Brian Hall（Beej）写的网络编程指南，以 C 语言讲 Berkeley 套接字 API，覆盖 IPv4 与 IPv6、TCP 与 UDP、客户端与服务器的写法，并附有可运行的示例代码。语言口语化、好读，重点放在动手写出能工作的程序。内容偏经典，主要讲阻塞 I/O 和 select()，而不是现代的异步框架。

HN 为什么推荐它

HN 上的人长期把它当作学套接字的标准起点：写得清楚、容易读，有人自己或在课上用它入门，常说它是最好的免费编程书之一。也有人提醒它偏老派，只讲阻塞 I/O 和 select()，还有人觉得其中的服务器示例代码有些绕。

难度 3 / 5约 12 小时
适合谁

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先快速读背景部分，再从套接字基本调用读起
  2. 2照着示例代码自己敲一遍客户端和服务器
  3. 3读完后想了解高并发，再另找 epoll 或异步 I/O 的资料
  4. 4与作者的 C 语言指南配合着读
