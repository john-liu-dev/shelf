Daniel Holden 带读者用 C 语言从零写出一个 Lisp 方言的解释器，同时顺带学习 C 的指针、内存管理和错误处理。全书按章节循序渐进，每章在上一章的代码上增加功能，从解析器一路做到错误处理、宏和标准库，并有配套代码可对照。和只讲理论的语言实现教材相比，它更偏动手，适合同时补 C 和解释器两门课。

HN 为什么推荐它

HN 上的人常把它推荐给想学 C、或想入门语言实现的初学者，认为它是边做项目边学 C 的好路径，也比多数 Lisp 教程走得更远；评论里还夸排版漂亮。

难度 3 / 5约 25 小时
适合谁

想通过做项目学 C 和解释器的初学者

读之前最好知道
1基本的编程概念
2命令行与编译器使用

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从第一章起按顺序做，每章都自己敲代码并跑通
  2. 2遇到指针和内存管理的部分慢一点，别直接抄代码
  3. 3做完后可以自己加功能，比如新的内置函数
  4. 4想看更理论的解释器实现，再配合 SICP 读
