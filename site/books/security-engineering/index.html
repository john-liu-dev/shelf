Ross Anderson 的安全工程经典，副标题是构建可靠分布式系统的指南。内容从密码学、访问控制到银行、物理安全、核指挥控制等，强调安全是由技术、经济和人的行为共同决定的系统问题。可读性强，覆盖广而不求每个主题都深入，案例丰富。官网提供免费的在线版本，其中有的是早期版本，新版有部分章节免费。

HN 为什么推荐它

HN 上的人把它称为这个领域的“圣经”，说它讲安全是系统问题而不只是加密，面广、好读、有趣，非安全从业者也值得读；有一条批评质疑它的目标读者不明确。

难度 3 / 5约 60 小时
适合谁

想建立安全全局观的工程师与技术管理者

读之前最好知道
1基本计算机系统知识
2密码学入门概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1不必从头读到尾，挑感兴趣的章节读，如物理安全、银行
  2. 2先读前面讲整体思路的部分，再按需深入
  3. 3读后可对照 Anderson 配套的讲座视频
  4. 4注意在线免费版本可能是较早的版次
