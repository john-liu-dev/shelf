Rust 官方文档团队写的标准教程，由 Steve Klabnik、Carol Nichols、Chris Krycho 执笔，从安装和基本语法讲起，重点放在所有权、借用、生命周期、trait、错误处理等 Rust 独有的概念上。全书按章节循序渐进，配有可运行的示例代码和小项目。和只讲语法的速查文档相比，它更注重解释为什么 Rust 要这样设计。

HN 为什么推荐它

HN 上从 2015 年起就一直有人把它当作学 Rust 的首选，尤其用来解释所有权、借用、trait 和错误处理；有人说它值得读，哪怕不写 Rust 也能学到东西。早期有批评说教程过于乐观、对难点带过太快，错误处理部分也有点让人吃不消。

难度 3 / 5约 40 小时开放许可
适合谁

想系统学 Rust、已有一些编程经验的人

读之前最好知道
1任意一门编程语言基础
2命令行基本操作
3指针与内存的基本概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先顺序读完所有权、借用和生命周期相关的章节，这是 Rust 最难的部分
  2. 2每章的示例代码都自己敲一遍，让编译器报错并读懂错误信息
  3. 3错误处理和 trait 部分遇到困难时，回头对照示例再读一遍
  4. 4读完后做一个小项目，再按需查阅标准库文档
