Raphaël Hertzog 和 Roland Mas 合著的 Debian 官方风格管理手册，涵盖安装、软件包管理（apt）、系统配置、网络服务和安全等内容。内容全面，并随 Debian 版本更新。偏重 Debian 系发行版，通用的 Linux 概念也能从中学到。以 CC-BY-SA 许可免费放出，常被举作开放内容成功的例子。

HN 为什么推荐它

HN 上的人推荐它作为学 Linux 服务器管理的起点和 Debian 的参考手册，称它免费、全面又持续更新；评论里也常引用其中 apt、配置文件等具体章节。

难度 2 / 5约 40 小时开放许可
适合谁

想学服务器运维的 Linux 用户

读之前最好知道
1Linux 命令行基础
2网络基本概念

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从安装与软件包管理读起，边读边在虚拟机里操作
  2. 2把后面的服务配置当参考手册，按需查阅
  3. 3跟着做一遍，建一台自己的小服务器
  4. 4不熟的 Linux 概念，配合一本通用的 Linux 教程
