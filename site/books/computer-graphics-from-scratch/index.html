Gabriel Gambetta 的入门书，从最基本的画点（PutPixel）出发，一步步实现光线追踪器和光栅化渲染器。讲法偏直观，数学只讲够用的部分，与具体语言和图形 API 无关，读者可以用任何语言照着实现。和直接教 OpenGL 的教程相比，它先讲清渲染背后的原理。全书可在官方网站免费在线阅读。

HN 为什么推荐它

HN 上的人反复称它对初学者友好、讲解清楚、不啰嗦，并把它当作学图形学原理的好起点；有人说它比绑定 OpenGL 的教程更讲基础。

难度 2 / 5约 30 小时
适合谁

想弄懂渲染原理的编程初学者

读之前最好知道
1一门编程语言基础
2高中数学（向量、坐标）

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读光线追踪部分，边读边自己写出能出图的渲染器
  2. 2再读光栅化部分，对比两种方法的思路
  3. 3每章都动手实现，用自己熟悉的语言
  4. 4读完后可去读专门的图形学数学或着色器资料
