Lua 语言设计者之一 Roberto Ierusalimschy 写的 Lua 教程，这里是官网免费放出的第一版。从基本语法讲到表、函数、闭包、协程、面向对象和完整示例，行文简练，类似 Lua 界的 K&R。因为是第一版，内容对应较早的 Lua 版本，新特性需对照手册和新版。

HN 为什么推荐它

HN 上的人长期把它当作学 Lua 的标准入门书，称赞作者就是语言设计者、写得清楚简洁，尤其是协程、表和完整示例几章；也常建议配合官方参考手册读。有一条意见是 Lua 的面向对象文档分散。

难度 2 / 5约 20 小时
适合谁

想系统学习 Lua 的程序员

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1从头读到表和函数相关章节，并在 Lua 解释器里实际运行
  2. 2协程与完整示例章节值得精读
  3. 3读时对照当前 Lua 版本的参考手册，留意与第一版的差异
  4. 4有 C 语言背景的读者可再看与 C 交互的部分
