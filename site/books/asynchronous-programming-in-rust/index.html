Asynchronous Programming in Rust 由 Rust 异步工作组维护，是 Rust 官方的 async/await 指南，讲解 Future、执行器、Pin、Stream 以及异步代码的组织方式。书以解释概念为主，配有示例，帮助理解 Rust 的异步模型和其他语言的差别。它不是 Rust 入门书，更适合已学过 Rust 基础的人；部分章节仍不完整，需要和 tokio 等运行时文档配合。

HN 为什么推荐它

HN 上的人常引用它来解释 Rust 的 async 为什么存在、Pin 是什么、Future 是惰性的这些要点，也用来区分 reactor 和 runtime。同时有评论指出它不够完整，不同执行器之间难以互通这类问题书里没说透。

难度 4 / 5约 12 小时开放许可
适合谁

已掌握 Rust 基础、想写异步代码的开发者

读之前最好知道

2线程与并发基础

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读为什么要 async 的部分，建立整体印象
  2. 2Pin 一章不好懂，可先看后面再回头读
  3. 3配合 tokio 或其他运行时的文档一起读
  4. 4自己动手写一个小型异步服务来练手
