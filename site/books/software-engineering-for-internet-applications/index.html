Eve Andersson、Philip Greenspun、Andrew Grumet 合著，源自 MIT 的一门 Web 应用课程，讲怎样从零做出一个数据库驱动的网站。内容围绕数据建模、SQL、用户和权限、元数据与代码生成、规划和运营展开，并带有一个贯穿全书的项目式学习思路。和只讲某个框架的教程不同，它更关注设计原则和工程师的职业素养，具体技术栈相对陈旧，但基本思想仍被认为有价值。

HN 为什么推荐它

从 2007 年到 2026 年都有人推荐，理由包括：想自己做出大型网站的人可以按它走一遍、数据建模和元数据那一部分讲得好，还有人说它讲的软件工程职业素养是读过最好的；也有人提醒内容已经偏旧。

难度 3 / 5约 25 小时
适合谁

想系统理解怎样做 Web 应用的开发者

读之前最好知道
1基本的编程能力
2SQL 基础

怎么读

由 Claude 根据这本书和 HN 上的说法整理，可能有错
  1. 1先读讲设计和规划的部分，了解整体思路
  2. 2配合 Django 或 Rails 之类的现代框架做一个小网站
  3. 3数据建模与元数据相关章节值得细读
  4. 4技术细节陈旧时，只取思想，不必照搬工具
