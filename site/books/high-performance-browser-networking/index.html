Ilya Grigorik 从 Web 开发者的视角讲网络：先讲延迟与带宽、TCP、TLS 和移动网络，再讲 HTTP/1.1、HTTP/2、XHR、SSE、WebSocket 和 WebRTC 等浏览器能用的协议。重点放在这些协议如何影响页面性能，以及该怎样优化。文字清晰，不是协议规范式的枯燥写法，同时保持足够的技术深度。全书可在官网在线免费阅读。

HN 为什么推荐它

HN 上的人把它当作网络入门和性能优化的首选读物，称赞它对现代 Web 协议、HTTPS、WebRTC 讲得清晰权威，有人说这是一本推荐给任何开发者的书；也有人觉得对初学者略偏进阶。

难度 3 / 5约 15 小时开放许可
